## 2. 工况管理系统 (v4.0 新增)

### 2.1 功能概述

工况管理系统支持用户同时管理多个倒虹吸设计方案进行对比。SiphonPanel 采用单列主面板布局，不再在倒虹吸页面内部额外嵌入左侧工况栏；工况选择与管理统一放在底部操作栏“名称”右侧的紧凑控件中。

### 2.2 工况管理器 (CaseManager)

**文件**: `case_manager.py`

| 类 | 说明 |
|-----|------|
| `CaseInfo` | 工况信息（name, file_path, created_time, order） |
| `CaseManager` | 工况 CRUD 管理器 |

**存储**：
- 存储位置：`data/siphon_cases/` 目录
- 文件格式：`工况名.siphon.json`（JSON，含 `case_name`、`created_time`、`order` 元数据 + SiphonPanel `to_dict()` 数据）
- 支持导入导出：正式工况文件使用 `.siphon.json`；导入时兼容旧版“导出参数”生成的 `.json`，自动取其中 `data` 转为工况
- 工况文件导入导出只表示“单个倒虹吸方案交换”，不等同于项目管理里的 `.qxproj` 打开、保存或另存为
- `v / N / 弯管半径倍数` 的确认态不作为长期确认字段落盘；工况模式下只在当前运行内按工况临时记忆，软件重启后清空

**方法**：

| 方法 | 说明 |
|------|------|
| `create_case(name?)` | 创建新工况，自动命名"工况1"、"工况2"等 |
| `rename_case(case, new_name)` | 重命名工况（同步重命名文件） |
| `delete_case(case)` | 删除工况文件（无需确认，文件可从系统恢复） |
| `duplicate_case(case)` | 复制工况，自动命名"原名_副本" |
| `reorder_cases(new_order)` | 重新排序工况（持久化 order 字段） |
| `save_case_data(case, data)` | 保存工况数据（附加元数据） |
| `load_case_data(case)` | 加载工况数据 |

### 2.3 紧凑工况选择控件 (CaseSelector)

**文件**: `case_selector.py`

继承 QWidget，Fluent Design 风格。控件整体保持一行展示，避免占用主界面左侧空间。

**信号**：

| 信号 | 说明 |
|------|------|
| `case_selected(object)` | 工况切换（传递 CaseInfo） |
| `case_changed()` | 工况列表变更（新增、从文件添加、重命名、复制、删除） |

**UI 组件**：
- 标签：`工况:`
- 下拉框：列出所有工况，显示当前工况，长名称按控件宽度省略
- 快捷按钮：`+` 新建工况
- 更多菜单：`更多` 按钮展开重命名、复制、从文件添加工况、导出当前工况、删除

**布局约束**：
- 控件放在底部操作栏“名称”输入框右侧
- 下拉框限制固定宽度，避免挤压右侧“执行计算”
- 低频管理动作收纳到“更多”菜单，不常驻占用界面

**交互行为**：

| 操作 | 说明 |
|------|------|
| 下拉选择 | 切换工况，先保存当前工况，再加载目标工况 |
| `+` | 创建新工况，刷新下拉框并自动选中 |
| `更多 > 重命名` | 弹出文本输入框，确认后刷新并保持选中 |
| `更多 > 复制` | 复制当前工况，刷新并切换到副本 |
| `更多 > 从文件添加工况...` | 添加单个倒虹吸工况文件，支持 `.siphon.json`，并兼容旧版参数 `.json` |
| `更多 > 导出当前工况...` | 将当前单个倒虹吸工况文件导出到用户指定位置 |
| `更多 > 删除` | 删除前确认；删除后切换到第一个工况，没有工况时自动创建“工况1” |

### 2.4 工况集成（panel.py）

**关键方法**：

| 方法 | 说明 |
|------|------|
| `_on_case_selected(case)` | 切换工况：自动保存当前 -> 加载目标 -> 刷新 UI |
| `_mark_dirty()` | 标记数据修改 |
| `_do_autosave()` | 执行自动保存到当前工况文件 |

**自动保存触发时机**：
- 切换工况时自动保存当前工况
- 参数修改后 2 秒自动保存
- 计算完成后自动保存
- 关闭面板时自动保存
- 指定管径模式额外保存 `v_before_override / v_confirmed_before_override`，用于取消指定后恢复原拟定流速与原确认态

**工况内运行期状态**：
- `v / N / 弯管半径倍数` 的确认态由 `panel.py` 在内存中按工况名独立缓存
- 切换到其他工况前先保存当前确认态，切回时恢复本工况自己的确认态
- 软件重启后确认态全部清空，但工况参数与 `D_override`、`v_before_override` 等保存字段继续正常恢复

**首次打开**：自动创建"工况1"，纵断面几何保持空白，结构段表显示 7 类默认通用构件

### 2.5 示例数据兼容（历史兼容）

#### 概述

普通启动、新建空工况和空工况切换后，纵断面几何保持空白，不再自动添加内置示例纵断面；结构段表直接显示 7 类默认通用构件。
旧内置示例纵断面只保留兼容识别用途；一旦识别到这套历史示例，前端按空白纵断面几何处理，不再把它显示为正式数据，并保留或补齐 7 类默认通用构件。

#### 历史示例来源

DXF 示例文件：`倒虹吸水力计算系统/resources/导入纵断面dxf示例.dxf`

| 特征 | 数值 |
|------|------|
| 桩号范围 | 0.00m ~ 249.87m（已归零处理） |
| 竖曲线 | 4 个 ARC（R=5m） |
| 折点 | 1 个 FOLD |
| 高程范围 | 48.87m ~ 113.84m |
| 结构段 | 12 个（含进出水口） |

#### 状态管理

| 变量 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `_longitudinal_is_example` | bool | False | 是否识别到历史内置示例，仅用于兼容判断 |

#### 行为规则

| 场景 | 行为 |
|------|------|
| 首次打开 / 新建工况 | 自动创建空白几何工况，不再调用 `_add_example_longitudinal()`，结构段表显示 7 类默认通用构件 |
| 从推求水面线进入（有平面无纵断面） | 保持空白纵断面，使用已初始化的通用构件参与计算 |
| 从 `from_dict()` 加载空工况 | 保持空白纵断面几何；若缺少 `common_defaults_initialized`，迁移补齐 7 类通用构件 |
| 从 `from_dict()` 加载旧工况（仅有 `segments` / 旧 `plan_feature_points`） | 先自动迁移旧圆弧真源与纵断面节点；若识别为旧内置示例，则按空白纵断面几何处理，并补齐默认通用构件 |
| 工况切换时无纵断面数据 | 保持空白纵断面几何，结构段表保留 7 类默认通用构件 |
| 识别到旧内置示例纵断面 | 清空这套示例节点与对应纵断面段，并按空白纵断面几何处理 |
| 导入平面 DXF 或纵断面 DXF 任意之一 | 真实几何与已显示的通用构件组合，进入完整计算 |
| 用户通过“编辑纵断面节点”入口修改节点 | 自动清除历史示例标志 |
| 用户编辑纵断面结构段 | 自动清除历史示例标志 |
| 保存工况（`to_dict()`） | 空白几何按空白几何保存，不再回补示例纵断面 |
| 保存时标记 | 保存 `common_defaults_initialized: true`，用于区分“已初始化但用户删除了部分默认构件”和“旧工况需要迁移补齐” |

#### 空白态与兼容提示

| 元素 | 样式/行为 |
|------|------|
| 空白纵断面 | 画布显示空白几何提示，结构段区显示 7 类默认通用构件 |
| 历史示例识别 | 按空白纵断面几何处理，不再显示整套示例节点 |
| DXF 导入完成 | 正常显示真实几何，并与已显示的通用构件共同参与计算 |

#### DXF 导入确认

导入纵断面 DXF 时检查是否有现有数据，如有则弹出确认对话框，用户确认后才执行导入。导入平面 DXF 或纵断面 DXF 任意之一后，真实几何与启动时已显示的 7 类通用构件组合计算；用户删掉的默认通用构件不在自动加载时强制恢复。

## 3. 主面板布局 (SiphonPanel)

SiphonPanel 继承 QWidget，作为app_渠系计算前端Tab系统中的一个页面。主面板采用单列布局：上方为可视化画布，中部为参数设置区域，底部为操作栏。工况管理通过底部操作栏“名称”右侧的 `CaseSelector` 完成，不再占用左侧独立栏位。

### 3.1 区域 A：可视化画布

**控件**：`PipelineCanvas`（自绘 QWidget）  
**背景色**：深色 (#14141E)

**功能**：
- 绘制管道纵断面视图（绿色管线，弯管/折管高亮橙色）
- 绘制平面视图（IP点、转弯半径、方位角箭头）
- 平面 DXF 倒圆与纵断面竖曲线优先按 `arc_geometry` 绘制真实圆弧，不再退化成两点直连
- 纵断面节点重建后的直管/折管必须继续保留 `coordinates`，保证主画布、大图查看和底部统计使用同一份几何
- `绿点` 只用于弯管前后边界，不再表示普通直管分界点或折管边界
- `橙点` 统一表示转弯本体：弯管锚在圆弧中点且只标角度，折管锚在折点并同时标角度和折点高程
- 拥挤场景下点位始终保留；文字优先级为“橙点角度 > 折管橙点高程 > 弯管绿点高程”
- 自动视图切换（有纵断面数据则纵断面，有平面数据则平面）
- 鼠标滚轮缩放 + 拖拽平移
- 高程标注、节点编号、空白态提示

**工具栏**：
- 视图切换按钮（纵断面/平面）
- 缩放百分比标签
- 重置视图按钮

**信号**：`view_changed(str)`、`zoom_changed(float)`

### 3.2 区域 B：参数设置区域（QTabWidget，3个Tab）

#### Tab 1: 基本参数

采用左右分栏布局（QGridLayout），分为4个参数卡片（QGroupBox）。

**卡片1：设计参数**

| 控件 | 类型 | 说明 |
|------|------|------|
| 名称 | LineEdit | 作业名称，默认"倒虹吸" |
| 设计流量 Q | LineEdit | 必填 (m3/s) |
| 拟定流速 v | LineEdit | 必填 (m/s)，方案D确认交互 |
| 糙率 n | LineEdit | 默认 0.014 |
| 管道根数 N | _NumPipesWidget | 自定义 [-] 数字 [+] 控件，1~10 |
| 弯管半径倍数 n | LineEdit | R = n * D |
| 弯管半径 R | LineEdit | 计算值或手动输入，双向联动 |
| D显示行 | Label（只读） | 普通模式显示 `D设计 = ...（D理论 = ...）`；多管并联额外显示 `每管Q`；指定管径模式显示 `采用D = ...（实际流速 = ...）` |
| 指定管径 | CheckBox + LineEdit | 勾选且输入有效管径后，拟定流速框切为灰色只读并显示反算实际流速；取消后恢复勾选前的拟定流速 |

**确认交互机制**：
- **方案D（拟定流速）**：用户手动编辑触发"未确认"状态（黄色边框），Enter/失焦确认后变绿色边框，计算前强制验证
- **方案D确认态范围**：确认态按工况独立记忆，只在本次运行内有效；软件重启后清空
- **方案B（弯管半径倍数）**：用户修改后进入待确认状态，Enter/失焦后确认；未确认时计算弹出黄色InfoBar警告（不阻断）
- **管道根数**：值变化时重置确认状态，[+]/[-]点击视为确认

**卡片2：渐变段配置**

| 控件 | 说明 |
|------|------|
| 进口渐变段型式 | ComboBox（无/反弯扭曲面/1/4圆弧/方头型/直线扭曲面） |
| 进口渐变段系数 xi1 | LineEdit，型式变更自动联动，仅用于 ΔZ₁ |
| 出口渐变段型式 | ComboBox |
| 出口渐变段系数 xi2 | LineEdit，型式变更自动联动，仅用于 ΔZ₃ |
| 参考表按钮 | 弹出 L12CoeffRefDialog（表L.1.2参考表） |

**口径说明**：
- 上方 `xi1 / xi2` 只表示进口、出口渐变段系数
- 结构段表里的进水口/出水口行系数只表示构件局部损失，重新计算时计入 `ΔZ2`
- 编辑结构段表进出水口行时，不允许反向覆盖上方 `xi1 / xi2` 输入框

**卡片3：流速参数**

| 控件 | 说明 |
|------|------|
| 进口始端流速 v1 | LineEdit (m/s) |
| v2策略 | ComboBox（自动/v1+0.2/断面参数计算/指定输入） |
| 进口末端流速 v2 | LineEdit，根据策略可读/只读 |
| 出口始端流速 v_out | LineEdit (= 管道流速) |
| 出口末端流速 v3 | LineEdit (m/s) |

**v2策略联动**：
- **自动**：v2只读，计算后回填管道流速
- **v1+0.2**：v1变化时自动联动v2
- **断面参数**：双击提示标签打开 `InletSectionDialog`
- **指定输入**：v2可编辑

**卡片4：高级选项**

| 控件 | 说明 |
|------|------|
| 水损阈值 | LineEdit，位于紧凑参数区中栏右半区，计算完成后对比告警 |
| 加大流量设置 | 整宽流量条带：设计流量 `Q` + 考虑加大流量 + `按比例 / 按Q加大` + 当前模式输入 |
| 详细过程输出 | 默认生成，无需用户勾选 |

**当前布局补充**：
- “全局水力参数”卡片采用“上方整宽流量条带 + 下方紧凑参数区”结构，不再把设计流量 `Q` 与加大流量设置拆散。
- 整宽流量条带采用“左窄右宽”：左侧仅放 `设计流量 Q`，右侧放是否加大、输入方式和当前输入框，减少左侧空白并避免右侧挤压。
- 下方紧凑参数区的中栏拆成“左侧主参数 + 右侧提醒参数”；“水损阈值”放在“拟定流速”右侧，右栏只保留平面转弯半径倍数、`R` 和对应说明。
- 加大流量区保留 `按比例` / `按Q加大` 两种输入方式：`按比例` 可留空按规范自动查表，`按Q加大` 输入加大后的总流量且必须大于设计流量 `Q`。
- 界面上只显示短提示，完整规则通过 `?` 的悬停提示查看；该重排只调整 UI，不改变 `v1_inc / v2_inc / v3_inc` 的既有校验和项目保存字段。
- 加大流量与指定管径两个说明问号统一采用快速悬浮提示，目标延迟为 `200ms`；不改全局 tooltip 策略，也不恢复点击展开说明块。

#### Tab 2: 结构段信息

**三区表格**（QTableWidget，12列）：

| 列 | 标题 | 说明 |
|----|------|------|
| 0 | 序号 | 自动编号 |
| 1 | 分类 | 通用/平面/纵断面 |
| 2 | 类型 | 段类型（附加状态如"拦污栅(已配置)"） |
| 3 | 方向 | SegmentDirection |
| 4 | 长度(m) | -- |
| 5 | 半径R(m) | 弯管有效 |

## 3.5 平面DXF导入子系统（v3.0）

### 3.5.1 概述

平面DXF导入功能允许用户独立于纵断面导入平面工程坐标多段线，支持三种计算模式：
- **仅平面（独立计算）**：仅有平面数据，使用平面转弯局损和通用构件计算
- **仅纵断面（独立计算）**：仅有纵断面数据，使用纵断面竖向转弯局损和通用构件计算
- **平面+纵断面（独立叠加）**：同时拥有两种数据，平面局损与纵断面局损分别计算后相加，不做三维空间合并水损

### 3.5.2 状态管理

| 变量名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `_plan_source` | str | `'none'` | 平面数据来源追踪：`'none'`/`'dxf'`/`'water_profile'` |
| `_plan_undo_stack` | list | `[]` | 平面数据撤回栈（深拷贝快照） |

### 3.5.3 导入流程 (`_import_plan_dxf()`)

1. 校验DXF解析器可用性
2. 冲突保护：检测已有平面数据，弹窗显示现有数据来源，用户取消则中止
3. QFileDialog 选择 .dxf 文件（默认resources目录）
4. 调用 DxfParser.parse_plan_polyline(filepath)
5. 解析结果同时写入 `PlanFeaturePoint.arc_geometry / StructureSegment.arc_geometry`
6. 失败：InfoBar.error 显示错误消息
7. 成功：保存撤回快照 -> 替换数据 -> 设置来源 -> 刷新UI -> InfoBar.success

### 3.5.4 撤回功能

- `_push_plan_undo()`：深拷贝当前数据为快照，压入栈（深度限制20）
- `_undo_plan_import()`：弹出最新快照恢复，刷新UI

### 3.5.5 清空功能 (`_clear_plan_data()`)

确认对话框 -> 保存快照 -> 清空数据 -> 重置来源 -> 刷新UI

### 3.5.6 半径保护

| 数据来源 | 弯管段半径 | 特征点turn_radius |
|----------|-----------|-------------------|
| DXF (`locked=True`) | 跳过，保留DXF实际半径 | 跳过 |
| 推求水面线 (`locked=False`) | 更新为 `n * D_design` | 更新为 `siphon_radius` |

补充要求：
- DXF 导入的圆弧除了 `radius / angle` 兼容字段外，还必须保留 `arc_geometry` 真源
- autosave / 工况文件 / 项目保存恢复后，平面图与纵断面都要继续按圆弧显示
- 旧工况若缺 `longitudinal_nodes` 或缺 `arc_geometry`，加载时要先自动补建，再进入正常显示与保存链路
- 纵断面 `segments` 在节点/结构段互转、autosave 和项目保存恢复后，直管/折管都要继续保留 `coordinates`；若旧工况已有 `longitudinal_nodes` 但段坐标缺失，加载时要按节点自动补齐
- 手工改动后若无法构成有效圆弧，允许安全回退为直线/折线显示，但不能静默报错

### 3.5.7 数据冲突保护 (`set_params()`)

推求水面线传入平面数据时：检测冲突 -> 弹窗确认 -> 用户拒绝则跳过 -> 覆盖时先保存快照

### 3.5.8 删除策略

| 平面数据来源 | 平面段行为 |
|-------------|-----------|
| `_plan_source == 'water_profile'` | 拒绝删除 |
| `_plan_source == 'dxf'` | 允许删除 |

## 6. 交互逻辑

### 6.1 参数联动

| 触发 | 联动动作 |
|------|----------|
| Q / v / N 变更 | 200ms防抖 -> 统一刷新 D 显示行、弯管半径 R、平面弯管半径和相关系数 |
| 渐变段型式变更 | 自动查表填充 xi1/xi2 |
| v1 变更 | v2策略为"v1+0.2"时联动v2 |
| 弯管半径倍数 n 变更 | 联动R值显示、更新平面弯管半径 |
| 弯管半径 R 变更 | 反推 n = R / D设计 |
| 管道根数变更 | 普通模式实时刷新 `D设计 / D理论`；多管并联时额外显示 `每管Q` |
| 指定管径勾选或管径输入变化 | 有效时切换到 `采用D / 实际流速`，并让拟定流速框显示反算实际流速且灰色只读；无效或取消时恢复原拟定流速与确认态 |

### 6.2 计算流程

1. 普通模式验证拟定流速已确认（方案D）；指定管径已生效时改按采用D反算的实际流速参与计算，不再因为原拟定流速未确认而拦截
2. 验证管道根数已确认
3. 收集 GlobalParameters
4. 同步纵断面节点
5. 弯管半径倍数未按 Enter/失焦确认时警告（方案B，不阻断）
6. v2校验（非阻断警告）
7. 调用 `HydraulicCore.execute_calculation()`
8. 旧项目若能唯一恢复来源索引，先自动补回 `source_ip_index / source_long_node_index` 再继续；若无法唯一恢复，则改按自动值计算，`ignored_manual_overrides` 非空时弹出一次“手工局部系数未采用”的非阻断提示
9. 回填流速值（v1/v2/v_out/v3），标注来源
10. 水损阈值检查
11. 显示结果（自动切换到结果Tab）
12. 更新画布和数据状态
13. 触发回调（如有）
14. **自动保存当前工况（v4.0）**

## 8. 异常处理与用户体验

- **输入错误**：qfluentwidgets InfoBar（红色ERROR/黄色WARNING/绿色SUCCESS），定位到窗口顶部
- **防抖机制**：Q/v参数联动200ms防抖、画布更新100ms防抖
- **确认交互**：拟定流速/管道根数/弯管半径倍数分别有独立确认机制
- **确认态范围**：工况模式下的确认态属于运行期临时状态，按工况隔离恢复，不写成长期确认；软件重启后清空
- **冲突保护（v3.0）**：平面DXF导入/推求水面线传入平面数据时检测冲突，弹窗确认覆盖
- **撤回机制（v3.0）**：平面数据支持栈式撤回（深度20）
- **DXF半径保护（v3.0）**：DXF导入的弯管段（`locked=True`）保留实际几何半径
- **空白几何启动（v4.13）**：普通启动、新建空工况和空工况切换后保持空白纵断面几何，不再自动显示示例数据，结构段表立即显示 7 类通用构件
- **历史示例兼容（v4.12）**：识别到旧内置示例纵断面时，按空白处理
- **DXF导入确认（v4.0）**：导入纵断面DXF前检测已有数据，弹窗确认
- **默认构件初始化（v4.13）**：启动即显示 7 类通用构件；旧工况缺少 `common_defaults_initialized` 时迁移补齐一次；导入任一 DXF 后即可完整计算
- **工况自动保存（v4.0）**：参数修改2秒后、计算完成后、切换/关闭工况时自动保存；指定管径模式额外保存 `v_before_override / v_confirmed_before_override`
- **空几何引导**：无平面/纵断面几何时提示先导入 DXF 或手动添加管身段
- **文件占用处理**：Word/Excel导出捕获PermissionError
