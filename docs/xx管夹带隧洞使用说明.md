# xx管夹带隧洞使用说明

## 1. 这份说明讲什么

这份说明只讲当前确认后的最终口径。
如果你看到旧资料里还写着“隧洞留在 xx管 表里单独出参数”“圆拱直墙型还要填 H”或“弹窗里再录一遍隧洞参数”，请以本页为准。

## 2. 先记住 5 条规则

1. 隧洞参数正式来源只有表1手填或 Excel 导入。
2. 导出时按结构拆成上下两张表，不再把所有内容都塞进一张 `xx管` 表。
3. 上方普通渠道表继续跟随当前 `7/扩展项` 配置，隧洞回到这张表里。
4. 下方 `xx管` 表只保留 `有压管道 / 定向钻 / 顶管`。
5. 弹窗只做只读摘要和缺项提示；圆拱直墙型只认 `B`，不再使用 `H`。

## 3. 最短操作路径

1. 先在表1里填写，或从 Excel 导入隧洞参数。
2. 如果断面是圆拱直墙型，只填写 `B`。
3. 打开“有压管道水力计算”窗口。
4. 查看隧洞只读摘要和缺项提示。
5. 有缺项时回表1或 Excel 补齐，再重新计算和导出。

## 4. 导出后你会看到什么

### 4.1 上方普通渠道表

- 继续按当前 `7/扩展项` 配置输出。
- 隧洞回到这张表里展示。
- 如果需要调整隧洞参数，回表1或 Excel 修改。

### 4.2 下方 xx管 表

- 只保留 `有压管道 / 定向钻 / 顶管`。
- 继续使用固定 5 项表头。
- 不再单独展示隧洞底线。
- 不再单独展示隧洞断面参数文字。

## 5. 弹窗现在负责什么

- 读取表1或 Excel 里已有的隧洞信息。
- 做只读摘要。
- 提示缺少哪一项。

弹窗现在不负责：

- 新增一套隧洞录入入口。
- 单独修改或保存隧洞参数。
- 为圆拱直墙型额外录入 `H`。

## 6. 表1 / Excel 里要准备什么

- `断面类型`
- `断面尺寸`
- `坡降 i`
- `糙率 n`

当前口径补充：

- 圆形：填写 `D`
- 圆拱直墙型：只填写 `B`
- 其他断面：继续按当前已有字段填写

## 7. 最常见的误解

### 误解 1：夹带隧洞后，隧洞还留在下方 xx管 表里

不是。  
隧洞已经回到上方普通渠道表。

### 误解 2：弹窗里还要再录一遍隧洞参数

不是。  
参数只认表1或 Excel，弹窗只做只读摘要。

### 误解 3：圆拱直墙型还要补 H

不是。  
现在只认 `B`。

### 误解 4：xx管 表里还会单独显示隧洞参数

不会。  
下方 `xx管` 表不再单独展示隧洞参数。

## 8. 一句话总结

**现在 `xx管` 夹带隧洞的口径是：隧洞参数只认表1或 Excel；导出按结构拆成上下两张表；上方普通渠道表继续跟随当前 `7/扩展项` 配置并承接隧洞；下方 `xx管` 表只保留有压管道、定向钻、顶管；弹窗只做只读摘要；圆拱直墙型只认 `B`。**
