# 倒虹吸工况管理功能 PRD

> **已归档**：本文档内容已合并到 `倒虹吸水力计算系统/docs/倒虹吸水力计算软件 - 前端需求规格说明书 (Frontend SRS).md` v4.0 第 2 章（工况管理系统）。本文件保留供历史参考。

**归档日期**: 2026-03-06

## 功能概述
为倒虹吸水力设计面板添加工况管理功能，支持用户同时管理多个倒虹吸设计方案进行对比。

## 当前实现同步（2026-04-17）

- 倒虹吸面板的加大流量输入已统一支持 `按比例` / `按Q加大` 二选一，保留原“考虑加大流量比例系数”开关。
- `按比例` 输入允许留空并继续自动查表；`按Q加大` 输入的是加大后的总流量，必须严格大于设计流量 `Q`。
- 同一时刻只保留一种正式输入，另一项只做灰色换算提示；关闭开关时只隐藏，不主动清空上次输入。
- 工况保存新增 `inc_mode / inc_q_text`，旧工程若只有 `inc_percent`，恢复时默认仍按比例方式打开。
- 这次只统一“比例 / Q加大”入口，不改倒虹吸原有的 `v1_inc / v2_inc / v3_inc` 加大工况流速规则；勾选加大流量后，这些原有必填校验继续有效。
- 结果与导出说明统一增加 `输入方式 / 用户输入值 / 系统换算值` 三项文案。
- 加大流量换算改为内部高精度参与后续计算，不再先把比例或 `Q加大` 截成短位数再继续算倒虹吸链路。
- 加大比例统一显示为 3 位小数，公式代入中的比例小数 / 倍率统一显示为 5 位；最终结果值继续沿用结果区自己的显示口径。
- “全局水力参数”卡片已改为“上方整宽流量条带 + 下方紧凑参数区”两层结构；设计流量 `Q` 与加大流量设置被收进同一组，避免看起来像两类参数。
- 整宽流量条带采用“左窄右宽”布局：左侧只放 `设计流量 Q`，右侧放“考虑加大流量 / 按比例 / 按Q加大 / 当前输入框”。
- 加大流量说明改为“界面短提示 + `?` 悬停完整说明”；界面上不再直排长文案，优先保证 `1366` 宽场景下文字完整且卡片高度尽量不增加。
- 下方紧凑参数区继续保留三栏结构，但中栏已拆成“左侧主参数 + 右侧提醒参数”；“水损阈值”移动到拟定流速右侧，右栏只保留平面转弯半径相关项。

## 当前实现同步（2026-04-18）

- 倒虹吸面板的 `D` 行已改成实时显示，只要 `Q / v / N` 可算就立即更新，不再等用户先点计算或先确认拟定流速/管道根数。
- 普通模式下，单管显示 `D设计 + D理论`；多管并联额外显示“每管Q”。
- 指定管径生效后，`D` 行切换为“采用D + 实际流速”，拟定流速输入框显示按当前 `Q / N / D` 反算出的实际流速，并改为灰色只读。
- 取消指定管径后，会恢复勾选前的拟定流速和原确认态；为此工况保存新增 `v_before_override / v_confirmed_before_override` 两个恢复字段。
- 工况切换时，拟定流速、管道根数、弯管半径倍数的确认态已按工况独立恢复；这些确认态只在本次运行内记忆，软件重启后清空。

## 核心需求

### 1. 工况存储
- 存储位置：`data/siphon_cases/` 目录
- 文件格式：`工况名.siphon.json`
- 支持导入导出：`.siphon.json` 和 `.json` 格式

### 2. UI 布局
- 左侧边栏：工况列表（宽度可调节，默认 200px）
- 右侧主面板：倒虹吸设计界面
- 工具栏位置：边栏顶部（新建、导入按钮）

### 3. 工况操作
- **新建**：自动命名为"工况1"、"工况2"等
- **重命名**：双击工况名或右键菜单
- **复制**：自动命名为"原名称_副本"
- **删除**：无需确认，直接删除（文件可从系统恢复）
- **导入/导出**：支持单个工况的分享
- **拖拽排序**：支持手动调整工况顺序

### 4. 交互行为
- 单击切换工况
- 双击重命名
- 右键菜单：重命名、复制、导出、删除
- Delete 键删除当前工况
- 切换工况时，`拟定流速 / 管道根数 / 弯管半径倍数` 的确认态按工况独立恢复，不再串到其他工况
- `D` 行属于实时结果区，不再跟确认态绑在一起；只要当前工况的 `Q / v / N` 可算，就立即显示

### 5. 自动保存
- 切换工况时自动保存
- 参数修改后 2 秒自动保存
- 计算完成后自动保存
- 关闭面板时自动保存
- 自动保存会写入指定管径恢复字段 `v_before_override / v_confirmed_before_override`
- 工况确认态本身不落盘，只在本次运行内记忆；重启后重新进入时恢复为未确认

### 6. 示例数据处理
- 首次打开自动创建"工况1"
- 新工况自动添加纵断面示例数据（13个节点，包含竖曲线和折点）
- 示例数据来源：`倒虹吸水力计算系统/resources/导入纵断面dxf示例.dxf`
- 示例数据特点：
  - 桩号范围：0.00m ~ 249.87m（已归零处理）
  - 包含4个竖曲线（ARC，R=5m）
  - 包含1个折点（FOLD）
  - 高程范围：48.87m ~ 113.84m
- 保存时标记 `longitudinal_is_example: true`
- 工况切换时检测无纵断面数据则自动添加示例

## UI 设计

### 工况列表样式（Fluent Design）
- 圆角卡片式列表项（border-radius: 4px）
- 渐变色选中效果（#0078D4 到 #106EBE）
- 悬停半透明背景（rgba(0, 0, 0, 0.05)）
- 图标+背景双重标识当前工况

### 右键菜单
- 使用 qfluentwidgets 的 RoundMenu
- 带流畅动画（MenuAnimationType.DROP_DOWN）
- 图标：FluentIcon.EDIT, COPY, SHARE, DELETE

## 技术实现

### 核心文件
1. `case_manager.py` - 工况管理器（CRUD 操作）
2. `case_sidebar.py` - 工况侧边栏 UI（Fluent Design）
3. `panel.py` - 集成工况管理到主面板

### 关键方法
- `_on_case_selected()` - 切换工况
- `_add_example_longitudinal()` - 添加示例数据
- `_mark_dirty()` - 标记数据修改
- `_do_autosave()` - 执行自动保存
- `_update_D_theory()` / `_refresh_pipe_design_feedback()` - 统一刷新 `D` 实时显示、实际流速、R 与相关系数
- `to_dict()` / `from_dict()` - 保存并恢复 `v_before_override / v_confirmed_before_override`
- `_case_confirmation_states` - 仅内存的工况确认态缓存，负责按工况隔离恢复 `v / N / 转弯倍数`
