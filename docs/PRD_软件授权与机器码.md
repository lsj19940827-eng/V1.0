# 软件授权与机器码 PRD

## 1. 文档信息

- 版本：v1.0
- 更新时间：2026-09-01
- 适用模块：程序启动授权校验、软件激活窗口、管理员授权台账与在线黑名单
- 文档目标：统一机器码生成、旧授权兼容、激活校验和换机授权的产品口径。

## 2. 背景与问题

V1.3.10 及以前优先按 Windows `MachineGuid` 生成机器码。单位或电脑厂商使用同一系统镜像装机时，不同实体电脑可能保留相同的 `MachineGuid`，从而显示完全相同的机器码。此时管理员无法分别登记、恢复或吊销两台电脑。

机器码升级必须同时满足两个目标：

1. 新生成的机器码能够区分使用同一系统镜像的不同实体电脑。
2. 已经签发的旧授权在正常升级后继续有效，不要求所有用户重新申请。

## 3. 产品范围

### 3.1 本期范围

- 新主机器码组合 Windows `MachineGuid`、SMBIOS 系统 UUID 和主硬盘序列号。
- SMBIOS 系统 UUID 通过 Windows 固件表直接读取，避免依赖 WMI 权限；硬盘序列号保留 WMI 和 PowerShell/CIM 两级读取。
- 只向用户和管理员展示 SHA-256 结果，不展示、不写入授权台账、不上传原始硬件字段。
- 当前设备同时保留新版主机器码、V1.3.10 `MachineGuid` 单字段码和更早期硬件码三个候选。
- 软件激活窗口和启动校验均接受当前设备的任一候选机器码。
- 同一进程只采集一次硬件字段并缓存候选，避免重复启动系统命令和拖慢启动。

### 3.2 非本期范围

- 不自动改写 Windows 注册表或 `MachineGuid`。
- 不自动吊销换机用户的旧电脑授权。
- 不把主板 UUID、硬盘序列号、网卡地址等原始信息写入云端授权台账。
- 不改变 HMAC 签名、授权期限和在线黑名单的数据格式。

## 4. 机器码规则

### 4.1 新主机器码

当能够读取 SMBIOS 系统 UUID 或主硬盘序列号时，程序按固定版本前缀、`MachineGuid` 和可用硬件字段拼接后计算 SHA-256。字段名和字段顺序固定，避免不同版本因排序差异生成不同结果。

优先级如下：

1. `MachineGuid + SMBIOS UUID + 硬盘序列号`
2. `MachineGuid + SMBIOS UUID`
3. `MachineGuid + 硬盘序列号`
4. 硬件字段均不可用时回退 V1.3.10 的 `MachineGuid` 单字段机器码
5. `MachineGuid` 也不可用时回退更早期的网卡、硬盘和主机名组合码

### 4.2 兼容候选

候选按以下顺序去重：

1. 新主机器码
2. V1.3.10 `MachineGuid` 单字段机器码
3. 更早期网卡、硬盘和主机名组合机器码

激活窗口默认展示并复制第 1 个候选。启动校验和粘贴激活都必须接受全部候选，确保旧授权升级后继续可用。

## 5. 授权与换机流程

1. 同事从最新版软件激活窗口点击“复制机器码”。
2. 管理员检查机器码格式、重复记录和吊销历史。
3. 管理员登记姓名、授权时间、期限和状态，同步本地台账与 GitHub Gist。
4. 管理员生成带 HMAC 签名的授权码。
5. 同事粘贴授权码激活；程序校验签名、机器码候选、期限和在线黑名单。
6. 换机默认只新增新电脑授权，旧电脑是否吊销由管理员单独确认。

## 6. 异常与提示

- 新机器码与现有有效记录重复时，不直接覆盖，先确认是否为同一实体电脑。
- 两台不同实体电脑在新版仍显示相同机器码时，提示管理员采集诊断信息，不建议修改 Windows 注册表。
- 硬件字段全部读取失败时允许回退旧机器码，但应记录为兼容降级，不宣称已消除镜像碰撞。
- 在线同步失败时保留本地台账变化并明确提示重试，不静默宣称云端已成功。

## 7. 验收标准

- 相同 `MachineGuid`、不同 SMBIOS UUID 或硬盘序列号的两组输入生成不同主机器码。
- 新主机器码、V1.3.10 机器码和更早期机器码均为 64 位十六进制字符串。
- 旧授权机器码属于当前设备兼容候选时，升级后无需重新激活。
- 激活窗口粘贴任一当前设备候选所对应的合法授权码均能通过机器码校验。
- Windows 硬件读取命令静默执行，不弹出控制台窗口。
- 原始主板 UUID、硬盘序列号和网卡地址不进入本地或云端授权台账。
