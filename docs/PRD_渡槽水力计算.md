## 1. 背景与目标

### 1.1 背景

渡槽是渠系工程中跨越河流、道路、山谷等障碍物的输水建筑物。本模块提供渡槽槽身过水断面的水力设计计算功能，依据 **GB 50288-2018《灌溉与排水工程设计标准》** 第 9.4.1 条，完成断面尺寸确定、水力要素计算、超高验证及流速校核。

### 1.2 目标

- 支持 **U 形断面**（底部半圆 + 直立侧墙）和 **矩形断面**（可选倒角）两种槽身形式
- 自动搜索最优断面尺寸（最小槽身面积 / 深宽比约束）
- 同时计算设计流量与加大流量两种工况
- 提供详细计算过程输出、断面图预览、DXF 图纸导出、Word 计算书导出

### 1.3 用户角色

| 角色 | 描述 |
|------|------|
| 渠道设计工程师 | 输入设计参数，获取渡槽断面尺寸及水力计算成果 |

## 2. 规范依据

### 2.1 GB 50288-2018 第 9.4.1 条

水力设计内容应包括选择槽身纵向底坡、确定槽身过水断面尺寸、通过水面衔接计算确定渡槽底部纵向各部高程。

### 2.2 条文 9.4.1-1（流速推荐值）

> 槽身底坡应为缓坡（排洪渡槽除外），槽内设计流速宜为 **1.0 m/s ~ 2.5 m/s**。

- **实现方式**：流速作为推荐值，超出范围时输出提示信息（warning），但不阻止计算。

### 2.3 条文 9.3.3-4（深宽比控制条件）

> 梁式渡槽 U 形槽身的深宽比宜采用 **0.7 ~ 0.9**，拱式渡槽 U 形槽身的深宽比可减小。

- **深宽比定义**：H/(2R)，其中 H 为最终槽身总高；无拉杆时 H = R + f，有拉杆时 H = 不含拉杆的水力槽高 + 拉杆高度，2R = 槽宽。
- **自动搜索 R 时**：作为硬约束，不满足的 R 不参与候选。
- **手动指定 R 时**：作为软约束，计算正常完成并输出结果，若 H/(2R) 不在 [0.7, 0.9] 范围内，在 `warning_message` 中追加警告，包含：
  1. **方向提示**：说明 H/(2R) 偏大还是偏小，并指导用户增大或减小 R
  2. **建议 R 范围**：根据当前 H 反算 R ∈ [H/(2×0.9), H/(2×0.7)]，标注为近似值
  3. **原理说明**：解释深宽比 = (R+f)/(2R)，减小 R 使深宽比增大，增大 R 使深宽比减小

### 2.4 条文 9.4.1-2（超高控制条件）

> - **矩形断面**：设计流量时超高不应小于槽内水深的 1/12 加 0.05m；加大流量时超高不应小于 0.10m。
> - **U 形断面**：设计流量时超高不应小于槽身直径的 1/10（即 R/5）；加大流量时超高不应小于 0.10m。

- **实现方式**：超高为硬性控制条件，不满足时计算失败并给出明确错误信息和建议。有拉杆时分工况处理：设计流量按水面到槽顶（拉杆顶）校核，拉杆自身高度计入这段超高，同时校核设计水面距拉杆底 ≥ 0.10m；加大流量按水面到拉杆底的有效安全高差校核。
- **条件化逻辑**：当 `manual_increase_percent=0`（不勾选加大流量）时，仅校验设计流量超高要求，跳过加大流量超高约束（0.10m）；单项结果、断面图、批量结果表、批量详细报告、Word 和 DXF 也隐藏加大工况，错误信息显示“设计流量”而非“加大流量工况”。

### 2.5 加大流量比例（规范表）

| 设计流量 Q (m³/s) | 加大比例 |
|-------------------|---------|
| Q < 1             | 30%     |
| 1 ≤ Q < 5         | 25%     |
| 5 ≤ Q < 20        | 20%     |
| 20 ≤ Q < 50       | 15%     |
| 50 ≤ Q < 100      | 10%     |
| Q ≥ 100           | 5%      |

用户可指定加大比例，留空时按上表自动计算。

## 4. 水力计算核心

### 4.1 基础公式 — 曼宁公式

```
Q = (1/n) × A × R_hyd^(2/3) × i^(1/2)
V = (1/n) × R_hyd^(2/3) × i^(1/2)
R_hyd = A / P
```

其中 A = 过水面积，P = 湿周，R_hyd = 水力半径。

### 4.2 U 形断面水力要素

U 形断面由下半圆（半径 R）+ 两侧直墙（高度 f）组成。

**当 h ≤ R 时（水面在半圆部分）：**

```
θ = arccos((R - h) / R)
A = R² × (θ - sinθ × cosθ)
P = 2Rθ
```

**当 h > R 时（水面在直段部分）：**

```
A = πR²/2 + 2R × (h - R)
P = πR + 2 × (h - R)
```

**槽身总面积（用于最优搜索）：** 与过水面积公式相同，h 取总高。

### 4.3 矩形断面水力要素

**无倒角：**

```
A = B × h
P = B + 2h
```

**带倒角（角度 α，底边长 c）：**

倒角高度：`c_h = c × tan(α)`

倒角斜边长：`c_hyp = c / cos(α)`

当 h ≥ c_h 时（水深超过倒角高度）：

```
A = B × h - c × c_h
P = (B + 2h) - 2(c + c_h) + 2 × c_hyp
```

当 h < c_h 时（水深在倒角区域内）：

```
A = B × h - 2c × h + c × h² / c_h
P = (B - 2c) + 2 × (h / c_h) × c_hyp
```

### 4.4 水深反算

采用**二分法**迭代求解水深 h，使曼宁公式计算流量逼近目标流量。

| 参数 | 值 |
|------|------|
| 收敛容差 | 0.0001（相对误差） |
| 最大迭代次数 | 1000 |
| U 形搜索上界 | h_max = f + R |
| 矩形搜索上界 | 20.0 m |
| 精度终止条件 | \|h_high - h_low\| < 0.000001 |

### 4.5 U 形断面最优搜索逻辑

**未指定 R 时**，自动搜索最小槽身面积对应的 R：

| 参数 | 值 |
|------|------|
| 搜索范围 | R = 0.2 m ~ 15.0 m |
| 搜索步长 | 0.01 m |
| f/R 约束 | 0.4 ~ 0.6 |
| H/(2R) 约束 | 0.7 ~ 0.9 |
| 初拟 f/R | 0.4 |
| 优化目标 | 最小化 `calculate_u_total_area(H, R)` |

**搜索流程**（逐 R 遍历）：

1. 初拟 f/R = 0.4，计算 H_初 = R + f
2. 反算加大流量水深 h_inc
3. 计算需求总高；有拉杆时按 `H_total ≥ h_design + R/5`、`H_total ≥ h_design + tie_rod_height + 0.10` 与 `H_total ≥ h_inc + tie_rod_height + 0.10` 三个条件折算水力槽高
4. 若需求总高 > H_初，则调整 f/R（钳位到 0.4~0.6 范围）
5. 向上取整总高到 2 位小数
6. 验证：加大流量超高 ≥ 0.10m，设计流量超高 ≥ R/5
7. 验证：H/(2R) 在 0.7~0.9 范围内
8. 记录满足约束且面积最小的 R

**指定 R 时**：

1. 初拟 f/R = 0.4，计算 H
2. 反算加大水深，验证超高
3. 若不满足，调整 f/R（钳位 0.4~0.6）
4. 验证两种工况超高，不满足则报错并给出建议

### 4.6 矩形断面搜索逻辑

**指定槽宽 B 时**：

1. 反算设计/加大水深
2. 设计流量总高需求：H1 = h_design + h_design/12 + 0.05
3. 有拉杆时补充设计拉杆底净距需求：H1b = h_design + tie_rod_height + 0.10
4. 加大流量总高需求：H2 = h_inc + 0.10；有拉杆时为 H2 = h_inc + 0.10 + tie_rod_height
5. 取 H = max(H1, H1b, H2)，向上取整 2 位小数；无拉杆时不使用 H1b

批量 Excel 导入同步说明（2026-03-27）：
- 对 `渡槽-矩形`，若真实导入行已填写 `B`，批量计算固定走本分支，即使同一行也填写了 `H/B`。
- 导入 `H/B` 仅用于冲突提示，不再触发“按深宽比重新搜索 B”的回退。

**未指定 B 时**（按深宽比搜索）：

1. 深宽比 α = 用户值 或默认 0.8
2. B 从 0.50m 到 20.0m，步长 0.01m
3. 目标总高 H_target = B × α
4. 对每个 B：反算水深 → 计算超高需求 → 向上取整
5. 取第一个满足 H ≤ H_target 的 B（最小宽度解）

### 4.7 拉杆高度、总高与超高口径

当用户填写 `tie_rod_height` 时：

```
H_total = H_hydraulic + tie_rod_height
tie_bottom_height = H_total - tie_rod_height
Fb_design = H_total - h_design
design_tie_bottom_clearance = tie_bottom_height - h_design
Fb = tie_bottom_height - h_increased
increased_tie_bottom_clearance = tie_bottom_height - h_increased
```

- `tie_rod_height`：拉杆自身尺寸高度；程序按拉杆顶与槽顶齐平处理，因此拉杆底位于槽顶以下 `tie_rod_height`。
- `H_hydraulic`：不含拉杆的水力槽高，用于水深反算和确定水流可用空间。
- `H_total`：含拉杆的槽身结构总高，是结果页、H/B、H/(2R)、总面积和图纸尺寸中的主显示高度。
- `tie_bottom_height`：拉杆底控制高；有拉杆时设计和加大流量都以该高度校核拉杆底净距。
- `Fb_design`：设计流量槽顶超高，拉杆高度包含在这段超高内。
- `design_tie_bottom_clearance`：设计水面到拉杆底净距；有拉杆时必须 ≥ 0.10m。
- `Fb`：加大流量有效超高；无拉杆时等同水面到槽顶，有拉杆时为水面到拉杆底。
- `increased_tie_bottom_clearance`：加大水面到拉杆底净距；有拉杆时与 `Fb` 同值。
- 超高正常来讲是包括了拉杆高度的，但是设计流量不仅要满足槽顶规范超高，还要保证设计水面距拉杆底 ≥ 0.10m。
- 只考虑设计流量时，有拉杆结构总高按 `H_total = h_design + max(Fb_design_min, tie_rod_height + 0.10)` 控制；例如 `h_design=0.8m`、规范超高 `0.2m`、拉杆高度 `0.3m` 时，`H_total=0.8+0.4=1.2m`。

### 4.8 超高计算与验证

| 工况 | U 形断面 | 矩形断面 |
|------|---------|---------|
| 设计流量 | Fb_设计 = H_total - h_design ≥ R/5 | Fb_设计 = H_total - h_design ≥ h_design/12 + 0.05 |
| 设计流量（有拉杆） | design_tie_bottom_clearance = tie_bottom_height - h_design ≥ 0.10m | design_tie_bottom_clearance = tie_bottom_height - h_design ≥ 0.10m |
| 加大流量 | Fb_加大 = tie_bottom_height - h_inc ≥ 0.10m | Fb_加大 = tie_bottom_height - h_inc ≥ 0.10m |

无拉杆时，`tie_bottom_height = H_total`，因此加大流量口径与旧口径一致。

不满足任一条件即判定计算失败，返回 `success = False` 和详细错误信息。

### 4.9 流速校核

| 项目 | 要求 |
|------|------|
| 推荐范围 | 1.0 ~ 2.5 m/s |
| 超出处理 | 输出 warning_message，不阻止计算 |
| 过小提示 | "流速过小，可能造成淤积" |
| 过大提示 | "流速过大，可能造成冲刷" |

## 10. 错误处理

### 10.1 输入验证

| 条件 | 处理 |
|------|------|
| Q ≤ 0 | 阻止计算，InfoBar 提示 |
| n ≤ 0 | 阻止计算，InfoBar 提示 |
| slope_inv ≤ 0 | 阻止计算，InfoBar 提示 |
| v_min ≥ v_max | 阻止计算，InfoBar 提示 |
| 倒角参数不完整 | 弹出 `fluent_question` 对话框 |
| 深宽比 ≤ 0 | 计算引擎返回错误 |
| 指定槽宽 ≤ 0 | 计算引擎返回错误 |
| 拉杆高度 < 0 | 阻止计算或计算引擎返回错误 |

### 10.2 计算错误

| 条件 | 处理 |
|------|------|
| 水深反算失败 | `success=False`，提示计算失败 |
| 超高不满足规范 | `success=False`，提示具体不满足哪条规范及建议 |
| 未找到满足约束的解 | `success=False`，提示调整参数 |
| 指定 R 过小 | `success=False`，建议增大 R 或改用自动搜索 |

### 10.3 导出错误

| 条件 | 处理 |
|------|------|
| 未计算即导出 | InfoBar 警告 |
| 缺少 ezdxf | InfoBar 提示安装命令 |
| 缺少 python-docx | InfoBar 提示安装命令 |
| 文件被占用 | InfoBar 提示关闭文件 |
| 其他异常 | InfoBar 显示错误详情 |
