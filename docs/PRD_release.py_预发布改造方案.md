# 已废弃：`tools/release.py` 预发布双通道改造方案

> 状态：历史归档，2026-03-17 起不再作为当前实现依据。  
> 原因：仓库已收敛为“正式 Release + 正式 Gist”单通道，不再维护测试 Gist 或用户侧预发布入口。

## 当前真实状态

- `tools/release.py` 仅支持正式发布，不再支持 `--prerelease`。
- 更新清单只写正式 `GIST_ID`，不再存在 `GIST_ID_TEST`。
- 客户端检查更新弹窗不再提供“测试（预发布）”切换。
- 通用补丁当前只对近版本开放，默认最低补丁版本为 `1.1.9`；更老版本直接下载全量包。
- 如果补丁删除文件过多，或总覆盖量过大，构建阶段会直接跳过补丁，只发全量包。
- 补丁安装在 `validate` 阶段会继续显示“正在解压补丁包”“正在校验补丁适用性（x/y）”。
