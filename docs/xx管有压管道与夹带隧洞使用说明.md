# xx管有压管道与夹带隧洞使用说明

> 适用对象：录入人员、复核人员、项目负责人  
> 适用范围：`xx管` 渠道级别下，使用“有压管道水力计算”功能时，涉及 `有压管道 / 定向钻 / 顶管 / 隧洞` 的整线操作  
> 更新时间：2026-04-03

## 1. 这份说明解决什么问题

这份说明主要解决下面几类常见问题：

- 一条 `xx管` 整线里既有普通有压段，又夹带一段或多段隧洞时，用户到底该怎么操作。
- 纵断面 DXF 应该准备几份，画到哪里，哪些地方可以留空。
- 隧洞参数应该填在哪一张卡里，哪些是必填，哪些只是校核。
- 点“开始计算”后为什么会被拦住，提示语分别代表什么。
- 导出后的纵断面里，普通段和隧洞段分别怎么看。

如果你只想先把事情做完，可以先看第 3 章“最短操作版”。  
如果你已经遇到报错或导出结果看不懂，可以直接跳到第 8 章和第 9 章。

## 2. 先记住三句话

- 整线只导入一份纵断面 DXF。
- 隧洞不单独导入 DXF，按参数自动生成。
- 先导入整线 DXF，再补隧洞参数，最后开始计算。

只要把这三句话记住，绝大多数操作都不会走偏。

## 3. 最短操作版

适合已经熟悉表格、只想快速完成操作的用户。

1. 在表 1 里先把节点、结构形式、名称、桩号等基础数据准备好。
2. 点击工具栏里的“插入渐变段”。
3. 点击“有压管道水力计算”。
4. 在弹窗最上方的整线卡里，点击“导入纵断面DXF”，导入这条整线的纵断面。
5. 如果这条整线夹带隧洞，到每一张隧洞分段卡里填写：
   - 断面类型
   - 进口底高
   - 坡降 `i`
   - 对应断面参数
6. 如有需要，用“预览”检查一下。
7. 点击“开始计算”。

## 4. 开始前要准备什么

### 4.1 必要前提

在点“有压管道水力计算”之前，建议先确认下面几件事：

- 表格中已经有完整的节点数据。
- 相关结构形式已经录入完成。
- 该条线确实属于 `xx管` 渠道级别。
- 已经执行过“插入渐变段”。

如果前置条件没满足，系统一般会直接提示，不会进入正式计算弹窗。

### 4.2 结构形式怎么理解

这次功能最常见的结构形式有 4 类：

- `有压管道`
- `定向钻`
- `顶管`
- `隧洞`

对用户来说，可以把它们理解成两大类：

- 普通承压段：`有压管道 / 定向钻 / 顶管`
- 参数生成段：`隧洞`

区别在于：

- 普通承压段继续靠整线纵断面 DXF 取高程。
- 隧洞段不再要求你另外准备隧洞专用 DXF，而是靠参数自动生成。

### 4.3 导入资料要准备几份

对于一条 `xx管` 整线：

- 纵断面 DXF 只需要 1 份。
- 这 1 份 DXF 只需要覆盖非隧洞段。
- 隧洞段允许在 DXF 中留空。

换句话说：

- 纯有压整线：1 份 DXF，覆盖整线。
- 夹带隧洞整线：仍然只要 1 份 DXF，但只覆盖普通段和定向钻、顶管这类非隧洞段。

## 5. 进入功能后，你会看到什么

### 5.1 入口在哪里

入口在“推求水面线”面板的工具栏中：

- 按钮名称：`有压管道水力计算`

如果前面还没插入渐变段，系统常见提示是：

- “请先点击工具栏的【插入渐变段】按钮……”

这时先不要反复点计算按钮，先回去补“插入渐变段”。

### 5.2 弹窗里有哪些卡片

在 `xx管` 模式下，弹窗通常会出现下面两类卡片。

#### 第一类：整线卡

整线卡一般显示为：

- 标题：`链路: 某某整线`

它的职责只有一个核心点：

- 统一负责整线纵断面 DXF 的导入、清空和预览。

整线卡上常见按钮有：

- `导入纵断面DXF`
- `清空纵断面`
- `预览`
- `平面图 / 纵断面`
- `重置`

你可以把整线卡理解成：

- “这条线的纵断面主入口”

#### 第二类：隧洞分段卡

如果整线里夹带隧洞，整线卡下面会多出一张或多张隧洞分段卡。

隧洞卡一般显示为：

- 标题：`管道: 某某隧洞`

它的职责不是导入 DXF，而是填写隧洞参数。

系统在卡片里会直接提示：

- “隧洞段不走专用 DXF，按‘进口底高 + 坡降 i’生成纵断面；出口底高仅作校核。”

这句话非常重要，建议原样写进培训材料。

### 5.3 为什么会同时看到整线卡和隧洞卡

很多用户第一次看到会误解，以为两张卡重复了。实际上不是。

- 整线卡负责“导入整线纵断面 DXF”。
- 隧洞卡负责“录入隧洞参数”。

两张卡是配合关系，不是二选一关系。

## 6. 标准操作流程

### 6.1 第一步：先处理整线卡

推荐无论有没有隧洞，都先处理整线卡。

操作顺序如下：

1. 找到目标整线对应的“链路”卡片。
2. 点击“导入纵断面DXF”。
3. 选择这条整线对应的纵断面 DXF 文件。
4. 导入后，如有需要，用“预览”查看。

补充说明：

- 导入前界面会固定提示下面这段说明：
  - `合格的纵断面 DXF 需要满足：`
  - `1. DXF 文件里有可识别的纵断面管道中心线，建议只保留这一根多段线。`
  - `2. 该轴线按 1:1 绘制，其中 Y 为管道中心线的真实高程（米）。`
  - `3. 若文件里有多条相近多段线，系统会优先识别更像纵断面的那条，必要时会请你确认。`
  - `4. 为提高识别成功率，建议把纵断面放在“纵断”或“纵剖”等清晰图层。`
- 如果你在 CAD 里把这条纵断面轴线重画成了反方向，系统现在会自动按桩号递增方向识别，不需要你先手工把 DXF 反过来再导入。

#### 这里最容易犯的错

- 错误做法：一条整线准备多份 DXF，普通段一份、隧洞一份。
- 正确做法：整线只导一份 DXF；隧洞靠参数生成。

#### 如果整线起点就是隧洞怎么办

这也是最常见的疑问之一。

正确做法是：

- 仍然只导入 1 份整线 DXF。
- 这份 DXF 不必从整线最起点画起。
- 只要从第一段非隧洞子段开始即可。

系统会自动把 DXF 第一点评到第一段非隧洞桩号，不需要你手工去把 DXF 起点硬凑到整线起点。

### 6.2 第二步：再处理隧洞分段卡

整线 DXF 导入完成后，再逐张填写隧洞卡。

每张隧洞卡都需要你确认这些内容：

- 断面类型
- 进口底高
- 坡降 `i`
- 出口底高校核
- 断面参数

注意顺序建议如下：

1. 先选断面类型。
2. 再填进口底高。
3. 再填坡降 `i`。
4. 再按断面类型填写对应尺寸。
5. 最后如果手头有资料，再补“出口底高校核”。

### 6.3 第三步：检查并开始计算

在点击“开始计算”前，建议快速检查 2 件事：

- 整线卡是否已经导入 DXF。
- 每一张隧洞卡的必填项是否已经补齐。

确认无误后，再点击：

- `开始计算`

## 7. 隧洞参数到底怎么填

### 7.1 哪些是必填

对于夹带隧洞的整线，下面这些内容是关键项：

- 整线卡：必须导入纵断面 DXF。
- 隧洞卡：必须填写有效的隧洞参数。

### 7.2 隧洞参数字段说明

| 字段 | 是否必填 | 说明 |
|---|---|---|
| 断面类型 | 必填 | 先决定隧洞属于哪一种断面 |
| 进口底高(m) | 必填 | 隧洞生成的起算点 |
| 坡降 i | 必填 | 必须是有效正数 |
| 出口底高校核(m) | 选填 | 仅用于核对，不作为主控制值 |
| 断面参数 | 必填 | 随断面类型不同而不同 |

### 7.3 支持的断面类型与参数

| 断面类型 | 需要填写的参数 |
|---|---|
| 圆形隧洞 | 洞径 `D` |
| 圆拱直墙型隧洞 | 底宽 `B`、净高 `H` |
| 马蹄形Ⅰ型隧洞 | 内半径 `r` |
| 马蹄形Ⅱ型隧洞 | 内半径 `r` |

### 7.4 “出口底高校核”怎么理解

这个字段很容易被误解成“系统按它来算”。实际上不是。

正确理解是：

- 系统真正生成隧洞纵断面时，按“进口底高 + 坡降 `i` + 起终里程”推算。
- “出口底高校核”只是拿来核对结果是否合理。

所以：

- 没有出口底高时，也可以先不填。
- 有出口底高资料时，建议填上，方便复核。

## 8. 多种典型场景怎么操作

### 8.1 场景一：整条线没有隧洞

这是最简单的场景。

操作方式：

1. 打开“有压管道水力计算”。
2. 只看整线卡。
3. 导入 1 份整线纵断面 DXF。
4. 预览无误后开始计算。

这个场景下，通常不会出现隧洞分段卡。

### 8.2 场景二：隧洞在整线起点

这是最容易紧张的场景，但操作并不复杂。

正确做法：

1. 先在整线卡导入 1 份 DXF。
2. 这份 DXF 从第一段非隧洞位置开始即可。
3. 不需要为了起点隧洞再准备第二份 DXF。
4. 再到隧洞卡填写进口底高、坡降 `i` 和断面参数。
5. 检查后开始计算。

记住一句话：

- 起点是隧洞，不代表 DXF 必须从隧洞起点画起。

### 8.3 场景三：隧洞夹在中间

这是最典型的“前面普通段 + 中间隧洞 + 后面普通段”场景。

正确做法：

1. 仍然只导入 1 份整线 DXF。
2. DXF 中只画前后非隧洞段。
3. 中间隧洞区间允许断开。
4. 到对应隧洞卡填写参数。
5. 再开始计算。

用户最常见的误区是：

- 以为中间断开会导致导入失败。

实际上：

- 只要 DXF 覆盖到所有非隧洞节点即可。
- 隧洞区间本来就允许留空。

### 8.4 场景四：一条整线里有多段隧洞

这种场景下，系统通常会出现：

- 1 张整线卡
- 多张隧洞分段卡

正确做法：

1. 整线 DXF 只导 1 次。
2. 每一张隧洞卡都要单独填写本段参数。
3. 不能只填第一段，其他段留空。

如果漏填某一段，点击“开始计算”时会被拦住。

### 8.5 场景五：已经做过一次，后来又要修改

这种情况最常见于：

- 重新收到一版更正后的 DXF
- 隧洞参数有调整
- 项目重开后继续修改

操作建议：

1. 如果要改整线纵断面，回到整线卡再次点击“导入纵断面DXF”。
2. 系统会提示是否替换旧数据。
3. 确认后，新的 DXF 会覆盖旧的整线纵断面。
4. 如果要改隧洞参数，直接去对应隧洞卡修改即可。

这套数据会跟项目一起保存。重新打开项目后，整线纵断面和隧洞参数会继续保留，通常不需要全部重填。

### 8.6 场景六：点“开始计算”时被拦住

如果被拦住，建议按下面顺序排查：

1. 先看整线卡是不是已经导入 DXF。
2. 再看有没有某一张隧洞卡缺参数。
3. 最后再看是否是 DXF 覆盖范围不足。

排查顺序不要反过来。  
大多数问题，前两步就能定位。

## 9. 导出结果怎么看

### 9.1 哪些导出会共用同一套口径

这次功能下，下面几种纵断面导出会共用同一套判断逻辑：

- 单独 DXF
- TXT
- 合并 DXF

对用户来说，可以简单理解成：

- 你在计算窗口里看到的整线和隧洞处理方式，会一致反映到这些导出里。

### 9.2 图里隧洞段和普通段分别怎么看

在 `xx管` 纵断面里，用户最容易看不懂的是第 4 行和第 5 行。

#### 第 4 行

标题仍然是：

- `管中心线高程（米）`

但实际口径已经分段处理：

- 普通有压段：显示中心线高程。
- 隧洞段：显示底高程。

也就是说：

- 标题不变。
- 隧洞段的数值含义已经改成底高。

这是有意设计，不是导出错误。

#### 第 5 行

普通段和隧洞段显示内容也不同：

- 普通有压段：继续显示材质和 DN。
- 隧洞段：改为显示断面参数文字。

常见显示示例如下：

- `圆形隧洞 D=2.4m`
- `圆拱直墙型隧洞 B/H=3.2/4.5m`
- `马蹄形Ⅰ型隧洞 r=1.8m`

### 9.3 建筑物名称行怎么看

在 `xx管` 图面里，不是所有段都会在“建筑物名称”行出字。

通常会出字的主要是：

- 隧洞
- 定向钻
- 顶管

普通有压管道本身一般不单独在这一行显示建筑物名称。

## 10. 常见提示与处理办法

下面这些提示最常见，建议在培训时直接逐条讲。

| 系统提示 | 它代表什么 | 该怎么处理 |
|---|---|---|
| 表格中没有数据，请先导入断面参数 | 表 1 还没准备好 | 先补表格基础数据 |
| 请先点击工具栏的【插入渐变段】按钮…… | 还没插入渐变段 | 先回去执行“插入渐变段” |
| 表格中没有有压管道同类数据…… | 当前没有有压管道/定向钻/顶管相关行 | 先检查结构形式是否录对 |
| 还差一步：请先为“某某整线”导入纵断面DXF，然后再开始计算。 | 这条整线还没导入纵断面 | 到整线卡点击“导入纵断面DXF” |
| 以下整线还没有导入纵断面DXF…… | 不止一条整线没导入 | 逐条补导入 |
| “某某隧洞”缺少隧洞进口底高 | 进口底高没填 | 回到该隧洞卡补填 |
| “某某隧洞”缺少有效坡降 i | 坡降为空、为 0、为负数或不是数值 | 改成有效正数 |
| 当前已有纵断面数据，导入DXF将替换现有数据。是否继续？ | 你正在覆盖旧的纵断面 | 确认后覆盖；不想覆盖就取消 |
| DXF解析器未加载 | 当前环境缺少 DXF 解析能力 | 联系维护人员检查环境 |
| DXF文件中未找到纵断面数据 | 选中的 DXF 里没有识别到有效纵断面 | 换文件或检查图层/图形内容 |
| 某某整线缺少可用于导入校验的桩号信息 | 系统找不到这条线的有效桩号锚点 | 先检查表 1 桩号和平面坐标 |
| 某某整线导入的纵断面未覆盖以下节点桩号 | 非隧洞段的 DXF 覆盖范围不够 | 重画或重导 DXF，优先检查非隧洞段；如果只是把整条轴线画反了，系统会自动纠正方向，不需要为这个报错专门翻转文件 |

## 11. 常见误解与正确理解

### 11.1 “隧洞也要单独导入一份纵断面 DXF”

错误。

正确理解：

- 隧洞不单独导入专用 DXF。
- 隧洞是按“进口底高 + 坡降 `i` + 起终里程”自动生成的。

### 11.2 “整线起点是隧洞，所以 DXF 必须从整线起点画起”

错误。

正确理解：

- 若整线起点是隧洞，DXF 从第一段非隧洞位置开始即可。
- 系统会自动对齐。

### 11.3 “出口底高校核是必填”

错误。

正确理解：

- 这是校核项，不是必填项。
- 主控制值仍是进口底高和坡降 `i`。

### 11.4 “只要 DXF 能导进来，就一定能开始计算”

不一定。

还要同时满足：

- 整线 DXF 已导入。
- 每一张隧洞卡的必填项已经补齐。

### 11.5 “报覆盖不足时，要重点检查隧洞段”

通常不是。

正确理解：

- 隧洞段本来就允许不靠 DXF 覆盖。
- 这类报错重点检查的是非隧洞段。

## 12. 推荐给一线用户的操作口诀

可以把下面这段直接放到培训 PPT 或操作卡里：

1. 先补表，再插渐变段。
2. 打开有压管道水力计算。
3. 整线只导一份 DXF。
4. 隧洞不导 DXF，只填参数。
5. 先导 DXF，再填隧洞参数，最后开始计算。

## 13. 建议给项目负责人的检查清单

如果你是复核人员或项目负责人，建议在交付前重点检查这几件事：

- 每条整线是否都已经导入纵断面 DXF。
- 每一段隧洞是否都有单独的参数卡，并且参数已填。
- 隧洞起点场景下，DXF 是否从第一段非隧洞位置开始。
- 导出图中第 4 行、第 5 行是否符合预期。
- 如果项目曾经反复修改过，是否已经重新导入最终版 DXF。

## 14. 一句话总结

把夹带隧洞的 `xx管` 整线想成“两层数据”最容易理解：

- 上层整线卡负责唯一一份 DXF。
- 下层隧洞卡负责每一段隧洞的参数。

只要按这个思路操作，整线导入、计算和导出就会稳定很多。
