# xx管有压管道与夹带隧洞使用说明

> 适用对象：录入人员、复核人员、项目负责人  
> 适用范围：`xx管` 渠道级别下，使用“有压管道水力计算”和纵断面导出时，涉及 `有压管道 / 定向钻 / 顶管 / 隧洞` 的整线场景  
> 更新时间：2026-04-10

## 1. 先看结论

- 纯 `xx管` 整线：继续按原来的固定 5 项表头导出。
- `xx管` 夹带隧洞：导出改成按结构拆成上下两张表。
- 上方普通渠道表继续跟随当前 `7/扩展项` 配置。
- 下方 `xx管` 表只保留 `有压管道 / 定向钻 / 顶管`。
- 隧洞参数正式来源只有表1手填或 Excel 导入。
- 弹窗只做只读摘要和缺项提示，不再单独展示一套可录入参数。
- 圆拱直墙型只认 `B`，不再使用 `H`。

## 2. 最短操作版

1. 在表1里录好隧洞参数，或先从 Excel 导入。
2. 如果断面是圆拱直墙型，只填写 `B`。
3. 打开“有压管道水力计算”窗口。
4. 查看隧洞只读摘要。
5. 缺项时回表1或 Excel 补齐，再重新计算和导出。

## 3. 导出规则现在怎么理解

### 上方普通渠道表

- 继续按当前 `7/扩展项` 配置输出。
- 隧洞回到这张表里。
- 隧洞不再挤进下方 `xx管` 表。

### 下方 xx管 表

- 只保留 `有压管道 / 定向钻 / 顶管`。
- 继续使用固定 5 项表头。
- 不再单独展示隧洞底线。
- 不再单独展示隧洞断面参数文字。

## 4. 弹窗现在负责什么

### 整线部分

- 继续处理整线计算入口和相关检查。

### 隧洞部分

- 读取表1或 Excel 里的已有值。
- 展示只读摘要。
- 提示缺少哪一项。

不在这里处理的内容：

- 不再新增一套隧洞录入。
- 不再单独保存隧洞参数。
- 不再为圆拱直墙型录入 `H`。

## 5. 表1 / Excel 里要准备什么

- `断面类型`
- `断面尺寸`
- `坡降 i`
- `糙率 n`

补充口径：

- 圆形：填写 `D`
- 圆拱直墙型：只填写 `B`
- 其他断面：沿用当前已有字段

## 6. 对旧项目怎么理解

- 本轮文档不承诺旧项目迁移保证。
- 如果是历史工程，请以当前表1或 Excel 数据重新核对。
- 低成本兼容只作为内部兜底，不作为对外说明口径。

## 7. 一句话总结

**现在 `xx管` 夹带隧洞的核心口径是：隧洞参数只认表1或 Excel；导出按结构拆成上下两张表；普通渠道表继续跟随当前 `7/扩展项` 配置；下方 `xx管` 表只保留有压管道、定向钻、顶管；弹窗只做只读摘要；圆拱直墙型只认 `B`。**
