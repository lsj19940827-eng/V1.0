## 一、模块概述

暗涵设计模块，为"渠系建筑物水力计算系统"的子模块之一，当前统一承接 `暗涵-矩形` 与 `暗涵-圆拱直墙型` 两类封闭断面暗涵。

### 口径同步（2026-04-14）

- 模块名称从“矩形暗涵设计”升级为“暗涵设计”家族；标准结构类型为 `暗涵-矩形` 与 `暗涵-圆拱直墙型`。
- 旧名称兼容：`矩形暗涵`、`矩形暗渠`、`暗渠` 统一归一为 `暗涵-矩形`，旧项目和 Excel 导入不改变业务含义。
- 表1项目加载/保存时，旧矩形暗涵名称统一回显并持久化为 `暗涵-矩形`，避免结构选择器继续显示旧口径。
- `暗涵-圆拱直墙型` 可以复用圆拱直墙型的几何计算，但必须按暗涵规则校核净空、渐变段和导出标题，不套用隧洞最小洞径、高宽比、围岩或 `xx管` 隧洞摘要规则。
- 表1、共享结果和表3需保留 `B / H_straight / H_total / theta_deg / manual_H_straight / used_manual_H_straight / h / A / P / R / V` 等关键参数；缺少圆拱参数时提示缺项，不得静默退化为矩形暗涵。
- 导出和断面汇总使用暗涵家族标题；`暗涵-*` 不进入 `xx管` 下方固定 5 项表，也不计入隧洞座数、隧洞长度或隧洞只读摘要。
- 倒虹吸出口局部阻力相关弹窗与断面汇总分类需补齐旧别名映射，旧工程中的 `暗渠 / 矩形暗渠 / 矩形暗涵 / 圆拱直墙型暗涵` 不得回退成默认明渠或普通矩形明渠。
- 加大流量输入已统一为 `按比例` / `按Q加大` 两种模式：默认按比例，比例可留空并继续自动查表；`按Q加大` 输入的是加大后的总流量，必须严格大于设计流量 `Q`。
- 同一时刻只保留一种正式输入，另一项只做灰色换算提示，不作为第二个必填项。
- 首次进入面板时也必须立即按当前模式收口显示；默认只显示“按比例”输入，不得同时把“按Q加大”一栏露出来。
- 工况保存新增 `inc_mode / inc_q_text`，旧工程仍兼容只保存 `inc_pct` 的历史数据；关闭“考虑加大流量”时只隐藏，不清空上次输入。
- 结果页、TXT、Word、DXF 统一补充 `输入方式 / 用户输入值 / 系统换算值` 三项说明，底层计算继续沿用比例参数口径。
- 加大流量链路已补成“内部高精度计算、展示再格式化”口径：比例、倍率和 `Q加大` 不在进入后续净空 / 流速 / 水深计算前提前截断。
- 结果页和导出里的加大比例统一显示为 3 位小数，公式代入里的比例小数 / 倍率统一显示为 5 位。
- 点击【清空】只清除计算结果、断面图、结果导航和导出缓存；左侧输入参数、加大流量模式与多工况列表保持用户当前输入，不再恢复程序默认值。

### 口径同步（2026-04-30）

- 计算结果详情顶部新增“重点结果汇总”普通卡片，放在每个工况结果块的最前面，不做滚动悬停。
- 汇总内容包含设计/加大流量下的水深、流速、净空高度、净空比例，以及矩形宽度/高度/宽深比或高宽比、圆拱直墙型宽度/总高/高宽比 H/B/直墙高度/拱顶圆心角和拱部参数；圆拱直墙型暗涵按 `H_total / B` 显示 H/B。
- 未启用加大流量或加大工况无可用结果时，不显示空值指标组，只显示短提示。
- Word 报告在每个工况计算过程前新增同口径“重点结果汇总”表；计算公式、DXF、批量计算和有压管道相关口径不变。

### 口径同步（2026-04-30，工况对比）

- 暗涵设计右侧输出区统一为“计算结果 / 断面图 / 工况对比”三个页签，计算完成后仍默认回到“计算结果”页。
- “工况对比”只复用已有 `all_results`，不重新计算；只列成功工况，参数变更后清空表格并提示重新计算。
- 对比表拆为“水力结果对比表”和“结构尺寸对比表”；结构尺寸表包含 `宽度 B`、`高度 H/总高 H`、`直墙高度 H直`、`H直来源`、`拱顶圆心角 θ`、`宽深比 β`、`高宽比 H/B`、`断面总面积 A总`；圆拱直墙型没有直接结果值时按 `H_total / B` 兜底计算 H/B。
- 单工况和多工况 DXF 均在断面图下方追加两张对比表；Word 报告在逐工况详细过程前先写两张总体对比表；圆拱直墙型暗涵仍只复用圆拱几何，不进入隧洞口径。

### 口径同步（2026-05-01，工况对比重点结果）

- 工况对比水力表同步重点结果口径，新增设计/加大净空高度和设计/加大净空比例列，未启用加大流量时加大列留空。
- 圆拱直墙型暗涵结构尺寸表补齐 `拱半径 R拱` 和 `拱高 H拱`，与重点结果汇总里的拱部参数保持一致。
- 删除原“控制余量类型 / 控制余量”摘要列，工况对比只保留设计/加大净空高度和净空比例等明确重点结果列。

### 口径同步（2026-05-01，断面图水位线）

- 单工况断面图统一显示一张设计流量图；启用加大流量且 `h_increased` 有效时，在同一坐标轴叠加“加大水位”虚线和 `h加大=x.xxm` 标注。
- 多工况断面图每个成功工况一个小图，按默认 2 列、窄窗口 1 列和断面图区域内部滚动承载；设计水位保留蓝色实线和水体填充，启用加大流量且加大水深有效时，在同图叠加“加大水位”虚线和 `h加大=x.xxm` 竖向双向水深尺寸标注。
- 暗涵-矩形和暗涵-圆拱直墙型均按真实断面宽度绘制加大水位线；加大水深缺失、为 0 或无效时不绘制。

### 口径同步（2026-05-07，圆拱水域与净空状态）

- 暗涵-圆拱直墙型断面图的水域填充复用共享圆拱几何，水位进入拱部时按断面边界顺序生成单一水域面，避免出现自交三角形。
- 重点结果汇总中的“净空校核”表示暗涵无压运行时的净空面积比例和净空高度校核：`Fb = H - h`，`PA = (H - h) / H × 100%`。
- 启用加大流量且加大结果有效时，“净空校核”以加大工况为控制工况；否则以设计工况为控制工况。
- 重点结果汇总优先沿用算法结果中的 `fb_check_passed`，没有该字段时才按净空比例和净空高度兜底判断，并保留与内核一致的边界容差，避免 `0.399972m` 显示为 `0.400m` 时被误判为“需注意”。

- 界面断面图的水平尺寸文字改用固定点数偏移，保持底宽 `B` 文字与尺寸箭头分离；计算、DXF 和 Word 规则不变。
- 圆拱直墙型继续使用共享圆拱水域几何，避免水域自交；计算、DXF 和 Word 规则不变。

### 1.2 核心能力

| 能力 | 说明 |
|------|------|
| 全局经济最优断面自动搜索 | 当底宽、宽深比和高宽比均留空时，以 β 为搜索变量，求解 B×H 最小的断面（β 无硬约束） |
| 指定底宽计算 | 用户指定底宽 B，系统搜索满足约束的最优断面高度 H |
| 指定宽深比计算 | 用户指定宽深比 β=B/h，系统搜索最优 B 和 H |
| **指定高宽比计算** | 用户指定高宽比 H/B，H=(H/B)×B，系统搜索满足约束的最小 B |
| 加大流量工况校核 | 自动或指定加大流量百分比，校核净空和流速 |
| 净空约束验证 | 按规范要求验证净空高度和净空面积百分比 |
| 暗涵家族类型 | `暗涵-矩形` 复用既有矩形暗涵能力；`暗涵-圆拱直墙型` 走暗涵规则，复用圆拱几何 |
| 断面图预览 | matplotlib 绘制设计/加大两种工况的断面对比图 |
| 导出 DXF | 带比例尺、图层、标注和工况对比附表的暗涵断面工程图 |
| 导出 Word | 高端咨询报告风格的计算书（含可编辑 OMML 公式和工况对比表） |

### 3.2 加大流量百分比查表

函数: `get_flow_increase_percent(design_Q)`

| 设计流量 Q (m³/s) | 加大比例 |
|--------------------|---------|
| Q < 1 | 30% |
| 1 ≤ Q < 5 | 25% |
| 5 ≤ Q < 20 | 20% |
| 20 ≤ Q < 50 | 15% |
| 50 ≤ Q < 100 | 10% |
| Q ≥ 100 | 5% |

用户可指定加大流量百分比覆盖自动计算值。

### 3.3 净空高度要求

函数: `get_required_freeboard_height_rect(H_total)`

根据 GB 50288-2018 第11.2.5条 表11.2.5（无压涵洞的净空高度）：

- 在任何情况下，净空高度均不得小于 **0.4m**
- 矩形涵洞进口净高 D ≤ 3m 时，净空高度应不小于 **D/6**
- 矩形涵洞进口净高 D > 3m 时，净空高度应不小于 **0.5m**

实现逻辑：
```
if H ≤ 3.0:  return max(0.4, H/6)
else:         return 0.5
```

### 3.4 水力要素计算

函数: `calculate_rectangular_outputs(B, H, h, n, slope)`

**输入**:
- `B`: 底宽 (m)
- `H`: 涵洞内侧总高度 (m)
- `h`: 水深 (m)，自动截断为 min(h, H)
- `n`: 糙率
- `slope`: 水力坡降 i

**公式**:
- 过水面积: `A = B × h`
- 湿周: `P = B + 2h`（矩形封闭断面，水面不计湿周）
- 水力半径: `R = A / P`
- 流量 (曼宁公式): `Q = (1/n) × A × R^(2/3) × i^(1/2)`
- 流速: `V = Q / A`
- 总断面面积: `A_total = B × H`
- 净空面积百分比: `freeboard_pct = (A_total - A) / A_total × 100%`
- 净空高度: `freeboard_hgt = H - h`

**输出**: 字典，键为 `A`, `P`, `R_hyd`, `V`, `Q`, `A_total`, `freeboard_pct`, `freeboard_hgt`

### 3.5 水深反算（二分法）

函数: `solve_water_depth_rectangular(B, H, n, slope, Q_target)`

- 搜索范围: `[0.00001, H]`
- 方法: 二分法，最大 100 次迭代
- 收敛判据: `|Q_mid - Q_target| / Q_target < 0.0001`
- 返回: `(水深, 是否成功)` 元组

### 3.6 主计算函数

函数: `quick_calculate_rectangular_culvert(...)`

**输入参数**:

| 参数 | 类型 | 说明 |
|------|------|------|
| `Q` | float | 设计流量 (m³/s) |
| `n` | float | 糙率 |
| `slope_inv` | float | 水力坡降倒数 (1/i) |
| `v_min` | float | 最小流速 (m/s) |
| `v_max` | float | 最大流速 (m/s) |
| `target_HB_ratio` | float, 可选 | 目标高宽比 H/B（指定后 H=(H/B)×B，搜索满足约束的最小B） |
| `target_BH_ratio` | float, 可选 | 目标宽深比 B/h |
| `manual_B` | float, 可选 | 指定底宽 (m) |
| `manual_increase_percent` | float, 可选 | 指定加大流量百分比 |

**设计模式判定逻辑**:

```
if manual_B 未指定 AND target_BH_ratio 未指定 AND target_HB_ratio 未指定:
    → 经济最优断面模式（β 参数化，B×H 最小）
elif target_HB_ratio 已指定:
    → 指定高宽比模式：对每个B，H=target_HB_ratio×B，搜索满足约束的最小B
elif target_BH_ratio 已指定:
    → 目标宽深比模式
elif manual_B 已指定:
    → 指定底宽模式
注：target_BH_ratio 与 target_HB_ratio 不可同时指定（过约束）
```

**搜索算法**:

#### 模式一：全局经济最优断面（β 参数化，v1.2 重写）

**原理**：明渠 β=2 对暗涵不是最优——H/B 建议值曾在 β 偏大时把 H 强行拉高，导致总面积 B×H 增加（v1.7已移除该硬约束）。新算法以 β 为搜索变量，解析计算 h_design 和 B，全局取面积最小。

**解析公式（设计工况，无需迭代）**：
```
h_design(β) = (Q·n/√i · (β+2)^(2/3) / β^(5/3))^(3/8)
B(β) = β · h_design(β)
```

**搜索流程**：
1. **阶段1**：粗扫 β ∈ [`BH_RATIO_MIN_RECT`, `BH_RATIO_MAX_RECT`]=[0.5, 2.5]，步长 0.02
2. 对每个 β：
   - 解析计算 h_design 和 B（无迭代）
   - 流速约束：`v_min ≤ V ≤ v_max`，`B ≥ 0.2m`
   - 热启动割线法求 h_inc（利用相邻 β 的 h_inc 作初值；失败回退带括号二分）
   - 解析求 H_min（净空面积≥10%、净空高度≥0.4m/H/6 取 max）；H_max（净空面积≤30%）
   - 约束验证：加大工况净空严格 [10%, 30%]；设计工况只检下限≥10%（无上限）
   - H/B、B/H 建议值（≤1.2）不参与 H_min/H_max 计算，仅在结果中标注 ⚠
   - 全量记录最小 B×H（不提前 break）
3. **阶段2**：在粗扫最优 β 附近 ±0.06，步长 0.002 细化
4. 若粗扫无解，扩展至 β ∈ [0.3, 3.5] 重试
5. 仍无解则退回普通搜索模式

#### 模式二：普通搜索（指定底宽/指定宽深比/全范围搜索）

1. B 范围：指定底宽时固定，否则 0.2~20.0
2. 宽深比范围：指定时 `[target±0.2]`，否则 `[0.5, 2.5]`
3. 双重循环遍历 B × β 组合
4. 同样的约束检查
5. 优选标准：
   - 有目标 β 时：β 偏差最小优先
   - 无目标 β 时：总面积最小优先

### 3.6 `暗涵-圆拱直墙型` 新增参数口径

`暗涵-圆拱直墙型` 复用圆拱直墙断面的面积、湿周、水面宽几何，但计算目的、净空校核、结果标题和导出归属都属于暗涵家族。

| 参数 | 说明 |
|------|------|
| `B` | 直墙段内宽，也是拱脚宽度 |
| `H_total` | 结构总高，含直墙段和拱部；可由自动搜索得到，也可由 `H直 + H_arch` 推导 |
| `theta_deg` | 拱顶圆心角，默认可沿用半圆拱 `180°` |
| `H_straight` | 直墙高度；留空时由 `H_total - H_arch` 推导，填写时按用户输入固定 |
| `manual_H_straight` | 用户输入的直墙高度，空值表示自动搜索 |
| `used_manual_H_straight` | 是否采用用户输入的 `H直` 固定几何 |
| `R_arch` | 拱半径，由 `B` 与 `theta_deg` 推导 |
| `section_type` | 固定为 `暗涵-圆拱直墙型` |

关键边界：
- 表1、共享结果、表3和导出链路必须完整保留 `B / H_straight / H_total / theta_deg`；缺失时提示补参数。
- `H直` 是可选固定输入：不填时继续自动搜索总高并按 `R拱 = (B/2) / sin(θ/2)`、`H拱 = R拱 × (1 - cos(θ/2))`、`H直 = H总 - H拱` 推导；填写时必须同时填写 `B`，并按 `H_total = H直 + H_arch` 固定几何核算。
- 固定 `H直` 只做设计流量、加大流量、流速和暗涵净空校核；校核失败时直接提示，不回退自动寻优。
- 水力几何可复用圆拱直墙型 helper；净空面积、高度、渐变段长度、断面汇总和导出标题按暗涵规则。
- 不进入 `xx管` 下方固定 5 项表；如出现在 mixed route，留在上方普通渠道表，不生成隧洞摘要。

- 版本: R2010
- 单位: mm (`$INSUNITS = 4`)
- 度量系统: 公制 (`$MEASUREMENT = 1`)
- 线型比例: `sf × 0.5`

### 5.5 绘制内容

1. **封闭矩形轮廓** — 4条实线（底/左/右/顶），暗涵有顶板
2. **顶板填充标记** — 两条斜线（-B/4 和 B/4 位置）

4. **加大水面线** — DASHED 虚线 + `▽ 加大水位 h=x.xxxm` 文字
5. **尺寸标注**:
   - 底部水平: `B=x.xxx m`
   - 左侧垂直: `h=x.xxx m`（设计水深）
   - 右侧垂直: `H=x.xxx m`（总高）
   - 右侧垂直（h_d 到 H）: `Fb=x.xxx m`（净空高度）
6. **参数文字块** — 右侧排列，包含：
   - 标题【矩形暗渠水力计算】
   - 比例: 1:xxx
   - ★ 经济最优断面（如适用）
   - 输入参数 (Q, n, i)
   - 断面尺寸 (B, H, β)
   - 设计流量 (h, A, V, Fb)
   - 加大流量 (比例, Q增, h增, V增, Fb增)

## 九、设计决策记录

### D1: 经济最优断面为默认模式
当底宽和宽深比均留空时，系统默认搜索总面积 B×H 最小的断面（β 无硬约束）。明渠 β=2 对带顶板的暗涵不是最优：H/B≤1.2 的结构约束会在 β 过大时将 H 强行拉高，浪费截面，实测可节省约 10~15% 材料。

### D2: 高宽比单向限制（仅限 H/B）
`H/B ≤ 1.2`，限制过窄断面（H过大），参考 GB 50288-2018 第11.2.5条表11.2.5。**不限制 B/H**（宽浅断面在工程中合理存在，如 B=2.4m、Q=3m³/s 的场景）。v1.6修复：移除了原代码中`B/H > 1.2`的错误双向拦截，该约束不来自规范，导致宽浅断面合法方案被误拒。

### D3: 搜索失败退化策略
经济最优断面搜索失败时，自动退回全范围普通搜索模式，而非直接报错。

### D4: 净空验证关键约束在加大流量工况
勾选加大流量时，关键约束在加大流量工况（10%~30% 严格）；设计流量工况只检下限≥10%，不检上限（H 由加大水深决定，设计净空自然偏大）。不勾选时，设计流量工况严格 10%~30%。v1.6修复：移除原代码中设计流量上限`+20%`的错误放宽。

### D5: 暗涵为封闭断面
与明渠的开放断面不同，暗涵绘图时顶部为实线+填充标记，表示封闭结构。

### D6: 圆拱直墙型暗涵只复用几何，不复用隧洞规则
`暗涵-圆拱直墙型` 与 `隧洞-圆拱直墙型` 的几何相似，但工程口径不同。新增类型应复用圆拱面积、湿周、水面宽等几何 helper，同时在净空、渐变段、表1/表3共享、断面汇总和导出归属上继续走暗涵家族，避免被 `xx管` 链路识别成隧洞。

### D7: 暗涵圆拱直墙型 H直 与隧洞交互对齐，但校核仍按暗涵
`暗涵-圆拱直墙型` 的 `H直` 采用与隧洞相同的输入口径：留空自动，填写固定；固定几何失败时不自动放大断面。区别只在校核规则：暗涵继续使用暗涵净空和暗涵导出归属，不套用隧洞最小洞径、围岩或 `xx管` 摘要逻辑。
