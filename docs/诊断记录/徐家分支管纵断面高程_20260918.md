# 徐家分支管纵断面高程核查（2026-09-18）

## 结论

上轮按区间替换旧节点的修复有效，但不完整。本轮实际错误成果复核又确认了解析器丢弃微小变坡点的问题，已补齐修复。最终以徐家原始DXF的折线坐标为基准，不能只以清空后成果为基准。

- 错误成果与清空后成果各有114列中心线高程，其中32列不同；两份DXF的管中心线均为146个绘图顶点，顶点、宽度与bulge逐项相同。
- 徐家原始DXF只有一条144顶点的折线，bulge全部为0，高程范围307.491608～341.422678 m；错误表有16个高程超出该范围。
- 原解析器仅保留大于0.5°的直线变坡，产生138个节点。清空后成果虽消除了旧节点污染，仍有9列偏离原线，差值约0.03～0.45 m。
- 最终修复保留144个真实几何节点；新增的6个微小变坡节点标记为NONE、转角计损值为0。大于0.5°才识别为FOLD的原计损分类阈值保持不变。
- 全部114列以原始折线逐段插值得到独立预期值；当前导入、保存回读、清空重导对照和实际DXF生成回读全部通过。

## 两处缺陷及修改

1. `PressurePipeConfigDialog._merge_longitudinal_nodes`原来只按桩号去重，新文件范围内不同桩号的旧节点仍可参与取值；原线几何另按覆盖范围合并，构成画线正确而文字错误的代码路径。现按新文件覆盖区间替换节点，区间外数据继续保留。
2. `DxfParser._build_longitudinal_nodes`原来把0.5°折管分类阈值同时用作几何删点阈值。小变坡节点一旦丢失，其前后高程被跨点连直线，产生新的插值偏差。现保留非共线变坡几何，微小变坡作为不计折管损失的普通节点。

## 证据边界

用户记不清此前是否导入过其他工程。错误DXF不保存当时的完整配置，当前配置也已是清空后的徐家数据，因此残留节点具体来源未确认。回归中的污染节点由错误表114个采样值重建，旧算法可复现114列错误表取值，但不等同于恢复当时缓存。实现缺陷与结果修复已经验证，不能据此指认某个历史工程。

两份成果的压力管道特性表管径分别为1.0 m与1.1 m，设计水位也不同。水位差异不能全部归因于纵断面问题；本次没有把清空后文件的水位复制到错误文件。原始DXF与两份成果均未改写；实际工程应在更新后的程序中重新导入、计算并导出。
