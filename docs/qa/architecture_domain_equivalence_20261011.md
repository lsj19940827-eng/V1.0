逐项比较了 5,997 个数值输出；加上输入共有 6,893 个数值。绝对、相对容差均为 $10^{-10}$。最大绝对差为 $1.9790118017995218\times10^{-13}$，来自全满平底圆断面原本接近零的净空面积百分比变为零；40 个非零浮点差均局限于平底圆内核的全满或超满工况。其余断面、系数、批量结果和文本比较均无差异。

旧断面入口的验证直接执行快照内 `BatchPanel._calculate_single` 的原始语法树及原计算导入，新入口调用 `BatchCalculationService._calculate_single`。有压批量计算则对比旧 `run_batch_scan` 与新 `calculate_batch`、`export_batch` 两阶段输出。新出口只能消费已完成快照；重导出不重新求解或查询目录、取消结果不落盘，由领域契约测试另外覆盖。

本报告验证的是正常依赖可用时的数值行为和源码构建入口。缺少正式系数服务时明确报错属于预期行为，由独立契约测试覆盖。本轮未重新打包或发布；上述结果也不替代桌面实际操作及已打包应用的验收。
