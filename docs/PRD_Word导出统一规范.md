# Word 导出统一规范

> **版本**：V1.0  
> **最后更新**：2026-10-09  
> **范围**：整个程序的 Word 计算书导出

## 1. 适用范围

明渠、渡槽、隧洞、矩形暗涵、有压管道、倒虹吸、推求水面线、泄水渠与陡坡、多流量段批量计算均遵守本规范。模板导出、模板缺失时的手工生成以及批量计算的独立封面均在范围内。

本规范统一版本文字、封面与目录之间的分页、所有表格的外观；各模块的计算内容、计算结果、公式、表内数值、列宽及合并关系继续由各模块提供。

## 2. 程序版本号

- 唯一来源为根目录 `version.py` 中的 `APP_VERSION`。
- 导出封面的版本文字及“计算程序”一节使用 `V{APP_VERSION}`，禁止固定写为 `V1.0`。
- 各模块追加的计算类型说明保留，例如“有压管道水力计算（球墨铸铁管）”。模块传入自定义程序文字时也必须引用同一版本源。
- 后续发版更新 `version.py` 后，新运行的程序导出报告自动采用对应版本，不需要逐个修改 Word 模板。
- 已经生成的历史 Word 文件不自动改写；新格式由更新后的程序重新导出获得。

## 3. 封面与目录分页

- 公共模板的封面结束后，目录从下一页开始，中间不得出现只有空段和分节符的空白页。模板缺失时保留手工生成路径的运行卡、强标检查表等既有内容页，不将这些内容页视为空白页删除。
- 保留各导出路径现有的分节、页眉页脚与页码规则；公共模板正文继续从第 1 页开始，手工回退及批量封面保留原有连续页码。
- 模板封面日期后的空段不得额外占页；原有封面分节属性附到日期段，相关书签保留。
- 刷新目录时，“目录”标题本身不进入目录条目。
- 模板文件不在导出过程中被覆盖，分页整理只作用于当次生成的文档。

## 4. 所有表格的统一外观

| 项目 | 要求 |
| --- | --- |
| 样式 | 普通网格表格，四周及内部均使用黑色细实线 |
| 底色 | 透明、无底纹；不得用白色填充代替透明 |
| 文字 | 黑色；不使用金色、蓝色或白色表头文字 |
| 表头 | 可保留加粗；数据表跨页时重复表头 |
| 数据行 | 无隔行底色，无彩色强调底色 |
| 选中状态 | 保留原有状态文字或符号，可加粗，不使用彩色高亮 |
| 数据与结构 | 保留内容、数值、公式、列宽及合并单元格 |

适用表格包括参数表、结果汇总表、候选方案对比表、工况对比表、建筑物长度汇总表、批量计算表、封面信息表、产品运行卡及强制性条文校审检查表，以及泄水渠模块自行追加的表格。

## 5. 实现入口

- `app_渠系计算前端/export_utils.py`：公共版本文字、模板分页和 `doc_apply_plain_table_style()`；三类公共数据表及封面表均使用同一表格格式函数。
- 各模块 `panel.py`：从 `version.py` 读取实际版本，生成对应“计算程序”文字。
- `app_渠系计算前端/spillway_steep_chute/report_export.py`：独立追加的表格同步使用公共表格格式函数。
- `app_渠系计算前端/report_meta.py`：程序名称与版本常量使用同一版本源。

旧调用中的 `with_full_border` 参数保留以兼容现有调用；无论该参数取值如何，Word 表格均显示完整网格。

## 6. 验收要求

1. 默认版本和模拟后续版本分别生成报告，验证模板、回退生成、批量封面及各模块传入文字均采用真实版本源。
2. 保存并重开文档，检查所有表格均无填充色、字体为黑色且具有完整网格，合并关系与公式保持一致。
3. 使用 Microsoft Word 原生重排和刷新目录，确认封面与目录紧邻、无空白页、目录不收录自身、正文起始页码为 1。
4. 生成包含跨页表格的样本，逐页检查无裁切、无重叠，并确认跨页重复表头。
5. 运行有压管道、倒虹吸、泄水渠等与导出内容相关的既有回归。

公共回归文件：`tests/test_word_export_common_unit.py`。设置环境变量 `RUN_WORD_COM_TESTS=1` 可同时执行 Microsoft Word 原生分页检查；未安装 Word 的环境仅执行结构与内容检查，不得据此宣称已完成原生分页验收。
