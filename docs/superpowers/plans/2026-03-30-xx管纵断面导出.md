# xx管纵断面 DXF 导出 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 `xx管` 渠道级别新增固定 5 行纵断面导出模板，按导入轴线 DXF 计算“管中心线高程”，并保证单独 DXF、TXT、合并 DXF 三条导出链路口径一致。

**Architecture:** 在现有 `cad_tools.py` 纵断面导出链路中增加清晰的 `xx管` 分支，而不是另建平行模块。结构类型扩展、导出校验、轴线高程插值、固定 5 行模板和绘图分支都以纯函数优先，普通渠类导出保持现状。导出所需的纵断面缓存继续复用 `PressurePipeManager.longitudinal_nodes`，通过 `panel.py` 暴露一个导出友好的访问接口。

**Tech Stack:** Python, PySide6, ezdxf, pytest

**PRD:** `docs/PRD_xx管纵断面导出.md`

```python
class StructureType(Enum):

def _is_xxpipe_channel_level(level: str) -> bool:
    return str(level or "").strip() in {"总干管", "分干管", "干管", "支管", "分支管"}


def _is_xxpipe_allowed_structure(struct_name: str) -> bool:
    text = str(struct_name or "").strip()
    return (
        text == "有压管道"
        or "隧洞" in text
        or text in {"定向钻", "顶管"}
    )


def _is_xxpipe_named_structure(struct_name: str) -> bool:
    text = str(struct_name or "").strip()
    return "隧洞" in text or text in {"定向钻", "顶管"}
```

```python
def get_pressure_pipe_longitudinal_nodes_for_export(self, rows=None) -> dict:
    targets = self._collect_pressure_pipe_export_targets(rows)
    manager = getattr(self, "_pressure_pipe_manager", None)
    to_dict = getattr(manager, "to_dict", None)
    if not callable(to_dict):
        return {}

    raw = to_dict() or {}
    pipes = raw.get("pipes", {}) if isinstance(raw, dict) else {}
    resolved = {}
    for target in targets:
        identity = target["identity"]
        name = target["name"]
        for key, row in pipes.items():
            if not isinstance(row, dict):
                continue
            if key == identity or (
                str(row.get("name", "") or "").strip() == name
                and str(row.get("flow_section", "") or "").strip() == str(target["flow_section"])
            ):
                nodes = row.get("longitudinal_nodes", []) or []
                if nodes:
                    resolved[identity] = list(nodes)
                break
    return resolved
```
