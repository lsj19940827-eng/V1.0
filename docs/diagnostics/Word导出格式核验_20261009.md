# Word 导出格式核验

日期：2026-10-09。当前源码版本：`version.py` 的 `APP_VERSION = "1.4.4"`。

## 变更与原因

| 问题 | 原因 | 修正 |
| --- | --- | --- |
| 导出仍显示 V1.0 | 公共封面、默认计算程序文字及 8 个模块入口各自写死版本 | 统一引用 `version.py` 的 `APP_VERSION` |
| 封面与目录之间空白页 | 模板日期后两个空段将分节符挤至下一页 | 将分节属性及书签移至日期段，移除多余空段，保留正文页码规则 |
| 表格颜色与底纹 | 公共表格主动写入深蓝、金色与隔行填充 | 所有表格统一黑字、黑色细网格及无底纹，独立泄水渠表格也使用同一函数 |

同时修正目录标题被 Word 目录刷新再次收录的问题。各模块计算内容、公式、数值和工况说明保持原口径。
