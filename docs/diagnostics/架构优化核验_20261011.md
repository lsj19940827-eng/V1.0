## 实施结果

1. **保存失败不再被掩盖。** 水面线嵌入断面数据收集失败向上传递，整份工程中止保存；工程、管理配置及独立工况共用原子 JSON 写入。恢复失败可回退，倒虹吸自动保存错误可见。
2. **批量计算从页面中抽出。** `BatchCalculationService` 不依赖 Qt，独立批量页与合并工作区共用；`BatchEditor` 提供编辑组件，其辅助容器保持隐藏，不构造完整隐藏批量页作为计算后端。
3. **工程与表格状态集中。** `ProjectCodec / ProjectSession` 负责版本、迁移、事务与会话；水面线 `ProfileTableState` 集中显示原文、精度、来源及行参数，稳定行身份随计算/保存/撤销往返。原表格作为适配器保留，解码逻辑独立于 Qt。
4. **后台任务有统一边界。** 断面批量、水面线及自动保存采用 `TaskRunner`；计算只访问快照，主线程应用结果。取消、输入变化、工程替换、运行期异常及结果应用异常分别验证。断面计算期间锁定会覆盖表3的并发操作，完成时同时核对表3状态。
5. **共享纯计算与导出分离。** 平底圆几何下沉至算法包，正式系数加载失败明确终止；有压专项覆盖值运行期只有一个来源。有压批量数值和导出分为两阶段，重导出不重算、不查询新目录。
6. **清理无效旧实现并建立检查。** 21 个方法共删除 22 份被覆盖的旧定义，最终有效方法 AST 全部不变。生产架构检查覆盖 160 个文件，0 项问题。历史测试替身隔离后能与真实 Qt 顺序、反序联跑。

完整契约见 [架构优化与工程状态 PRD](../PRD_架构优化与工程状态.md)。合并面板、水面线、项目保存、有压批量、倒虹吸、隧洞、暗涵 PRD 及根目录架构说明均已同步。
