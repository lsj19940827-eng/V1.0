# PRD：xx管程序规则与纵断面导出（已并入主 PRD）

## 1. 当前状态

- 本文件只保留检索摘要，完整规则以 `docs/PRD_有压管道批量计算_V1.0.md` 和 `docs/PRD_纵断面13项可选行与亭子口模板.md` 为准。
- 2026-04-10 起，`xx管` 夹带隧洞的导出口径改成按结构拆成上下两张表：
- 上方普通渠道表：继续跟随当前 `7/扩展项` 配置，承接隧洞和其他非 `xx管` 项。
- 下方 `xx管` 表：只保留 `有压管道 / 定向钻 / 顶管`，继续使用固定 5 项表头。
- 隧洞参数正式来源只有表1手填或 Excel 导入；弹窗只做只读摘要和缺项提示。
- 圆拱直墙型隧洞只认 `B`，不再使用 `H`。
- 隧洞不再在下方 `xx管` 表里单独展示底线或断面参数。
- 2026-04-12 起，压力管道特性表主长度按渠道级别分流：`支渠` 只统计被 `有压管道 / 定向钻 / 顶管` 前后夹住的中间隧洞；`支管` 继续按整线口径，并补回前置无压隧洞及其到首段有压结构之间的空档；DXF 主长度与弹窗汇总统一复用同一份结果。
- 2026-04-14 起，暗涵家族标准类型为 `暗涵-矩形` 与 `暗涵-圆拱直墙型`；旧 `矩形暗涵 / 矩形暗渠 / 暗渠` 兼容到 `暗涵-矩形`。
- `暗涵-*` 不进入下方 `xx管` 固定 5 项表，不展示管中心线、管材或隧洞摘要；如出现在 mixed route，留在上方普通渠道表。
- `暗涵-圆拱直墙型` 可复用圆拱几何，但必须走暗涵规则，不得按 `隧洞-圆拱直墙型` 的 `xx管` 只读摘要或参数口径处理。
