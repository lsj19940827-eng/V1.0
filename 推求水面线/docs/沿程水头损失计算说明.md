# 沿程水头损失计算说明

## 一、概述

沿程水头损失是水流在渠道中流动时，由于水流与渠壁之间的摩擦阻力而产生的能量损失。本程序采用底坡法计算沿程水头损失。

## 二、计算公式

### 2.1 基本公式

$$h_f = i \times L_{有效}$$

其中：
- $h_f$ = 沿程水头损失（m）
- $i$ = 底坡（无量纲，如 1/3000 = 0.000333）
- $L_{有效}$ = 有效长度（m）

### 2.2 有效长度计算

$$L_{有效} = \max\left(0,\ \Delta S_{MC} - L_{渐变段}\right)$$

其中：
- $\Delta S_{MC} = S_{MC,2} - S_{MC,1}$ = 两节点的里程MC桩号之差（m）
- $L_{渐变段}$ = 两节点之间渐变段的总长度（m），若无则为0

### 2.3 公式说明

**为什么不再扣除两端各半弧长？**

MC 桩号沿平面线路累计，两个相邻 MC 之间的里程差已经包含上一弯道后半段和当前弯道前半段。弧段同样存在渠壁摩阻，必须计入普通沿程摩阻。程序中的弯道公式只表示弯道二次流引起的附加损失，不替代弧段普通摩阻，因此两端半弧长仅作为几何核查信息保留，不参与有效长度扣减。

**为什么要扣除渐变段长度？**

渐变段有独立的水头损失计算公式，其沿程损失已在渐变段水损中计算，避免重复。

## 三、底坡数据

### 3.1 数据来源

底坡数据从表格的"底坡"列读取。表格中显示的是底坡的倒数形式（如3000），程序内部转换为真实底坡值：

$$i = \frac{1}{底坡列值}$$

例如：底坡列值 = 3000 → $i = \frac{1}{3000} \approx 0.000333$

### 3.2 底坡选取规则

计算时优先使用下游节点的底坡值：

```
slope_i = node2.slope_i if node2.slope_i > 0 else node1.slope_i
```

### 3.3 备用计算方法

当底坡数据缺失时，程序回退到曼宁公式反算水力坡降：

$$J = \left(\frac{v \cdot n}{R^{2/3}}\right)^2$$

$$h_f = J_{avg} \times L_{有效}$$

其中：
- $v$ = 流速（m/s）
- $n$ = 糙率
- $R$ = 水力半径（m）
- $J_{avg}$ = 上下游断面的平均水力坡降

## 四、计算示例

### 示例数据

| 参数 | 节点1 | 节点2 |
|-----|------|------|
| 里程MC（m） | 1000.0 | 1100.0 |
| 弧长（m） | 10.0 | 5.0 |
| 底坡 1/i | 3000 | 3000 |

渐变段长度 = 0（无渐变段）

### 计算过程

1. **里程差**
   $$\Delta S_{MC} = 1100.0 - 1000.0 = 100.0 \text{ m}$$

2. **有效长度**
   $$L_{有效} = \max(0,\ 100.0 - 0) = 100.0 \text{ m}$$

   节点1与节点2的弧长分别为 $10.0\text{ m}$、$5.0\text{ m}$，但相邻半弧段已包含在 $\Delta S_{MC}$ 内，不再扣减。

3. **底坡**
   $$i = \frac{1}{3000} = 0.000333$$

4. **沿程损失**
   $$h_f = 0.000333 \times 100.0 = 0.0333 \text{ m}$$

### 有渐变段的情况

若两节点之间有渐变段长度 = 20m：

$$L_{有效} = \max(0,\ 100.0 - 20.0) = 80.0 \text{ m}$$

$$h_f = 0.000333 \times 80.0 = 0.0267 \text{ m}$$

## 五、与其他损失的关系

### 5.1 水面线推求公式（顺推法）

$$Z_i = Z_{i-1} - h_{f,i} - h_{j,i} - h_{b,row,i} - h_{渐,i}$$

其中：
- $Z_{上}$ = 上游水位（m）
- $Z_{下}$ = 下游水位（m）
- $h_f$ = 沿程水头损失（m）
- $h_j$ = 局部水头损失（m）
- $h_{b,row,i}$ = 上一 $MC$ 到当前 $MC$ 区间的弯道附加水头损失（m）
- $h_{渐}$ = 渐变段水头损失（m）

### 5.2 总水头损失

$$h_{总,i} = h_{f,i} + h_{j,i} + h_{b,row,i}$$

注：渐变段损失单独显示在渐变段行，不计入节点的总水头损失。

对含弯道的弧段，普通摩阻已包含在 $h_f$ 中，弯道列只叠加二次流附加影响。第 $k$ 个完整弯道的附加损失为：

$$h_{b,k}^{full}=\frac{n_k^2L_{arc,k}v_k^2}{R_k^{4/3}}\frac{3}{4}\sqrt{\frac{B_k}{R_{c,k}}}$$

表3第 $i$ 行对应 $MC_{i-1}\rightarrow MC_i$，因此本行采用：

$$h_{b,row,i}=\frac{1}{2}h_{b,i-1}^{full}+\frac{1}{2}h_{b,i}^{full}$$

两个半弯道分别使用各自节点参数计算，不能先合并两段半弧长后统一套用当前节点参数。弯道相关总损失贡献仍应理解为“弧段普通摩阻 + 弯道附加损失”，不能把表3弯道附加列单独解释为规范所称的弯道段总损失。
